**December 2, 2025**, AWS **officially GA'd** its third-generation self-designed AI training chip **Trainium 3** at re:Invent 2025. This is a key upgrade to AWS's compute map: 3nm process, 4.4× compute improvement, 4× efficiency improvement, Trn3 UltraServer with 144 chips. This article breaks it down in detail.

{/* truncate */}

## Core Specifications

| Item | Trainium 2 (2024) | **Trainium 3 (2025-12 GA)** | Improvement |
|------|-------------------|------------------------------|------|
| Process | TSMC 4nm | **TSMC 3nm** | +1 gen |
| NeuronCore | 8× v3 | 8× **v4** | Arch upgrade |
| HBM capacity | 96 GB | **144 GB** | 1.5× |
| HBM bandwidth | 2.9 TB/s | **~4.5 TB/s** | ~1.55× |
| FP8 compute (dense) | 1,299 TFLOPS | **5,716 TFLOPS** (official 4.4×) | **4.4×** |
| BF16/FP16 | 667 TFLOPS | 1,300 TFLOPS | 2× |
| **Per-chip efficiency** | 1× | **4×** | 4× |
| **Memory bandwidth** | 1× | **4×** | 4× |
| NeuronLink | NeuronLink-v3 | **NeuronLink-v4** | New gen |
| TDP | ~700 W | ~700 W | Flat |
| Release | 2024-12 | **2025-12** | — |

> **Official 4.4× compute + 4× efficiency + 4× memory bandwidth** — Trainium 3 is AWS's flagship chip upgraded simultaneously across three dimensions.

## Trn3 UltraServer (Rack-Level)

| Item | Configuration |
|------|------|
| **Chip count** | **144 Trainium 3** |
| Total HBM | ~20.7 TB (144GB × 144) |
| NeuronLink-v4 | Fully interconnected, >10 TB/s bidirectional |
| FP8 compute (rack) | **52 PFLOPS** (dense) |
| BF16 compute (rack) | ~187 PFLOPS |
| TDP (rack) | ~100 kW |
| **Target models** | **400B+ param LLM training** |

> **Trn3 UltraServer = trains 400B models in a single rack.** One EC2 UltraCluster (>10 racks) supports **1.4T+ param giant model training**.

| Interconnect | NeuronLink-v3 | NeuronLink-v4 | New gen |
| Total HBM | 6.1 TB | ~20.7 TB | 3.4× |
| FP8 compute | ~83 TFLOPS | **52 PFLOPS** | **~626×** |
| Training capability | 70B+ LLM | **400B+ LLM** | — |
| Release | 2024-12 | 2025-12 | — |

> Trn3 UltraServer is one of the **highest cost-performance large-scale training solutions of 2026**.

## AWS Neuron SDK 3

- **Neuron SDK 3.x**: full optimization for PyTorch 2.4+ / JAX 0.4+ / TensorFlow 2.16+
- **Neuron Compiler 2.x**: auto-compile + graph optimization
- **NeuronX Distributed**: large-scale distributed training library (integrates with PyTorch FSDP)
- **NeuronX Nemo**: LLM fine-tuning framework (Megatron-LM equivalent)
- **vLLM 0.7+ optimized**: low-latency inference

> **AWS Neuron = an open-source ecosystem similar to ROCm**, all SDKs open-sourced on GitHub (aws-neuron).
