# NVIDIA Rubin

NVIDIA Rubin GPU was officially launched at **CES 2026** (January 2026), succeeding Blackwell as NVIDIA's next-generation AI accelerator chip. It features a novel **six-chip architecture** (Vera CPU + Rubin GPU + NVLink 6 + BlueField-4 DPU + ConnectX-9 SuperNIC + Spectrum-6 Ethernet Switch), forming a complete unified AI system.

## Core Specifications

| Parameter | Specification |
|-----------|---------------|
| **Architecture** | Rubin Architecture (Blackwell Successor) |
| **Process** | TSMC 3nm (N3/N3P) |
| **Transistor Count** | 336 billion |
| **Chip Design** | Dual compute chiplet + Dual I/O chiplet MCM design |
| **Announcement** | January 2026 (CES 2026) |
| **Mass Production** | Q3/Q4 2026 (sample delivery), Q1 2027 (volume production) |

## Architecture Features

### 1. Third-Generation Transformer Engine
- Supports **NVFP4 adaptive compression**
- Automatically optimizes precision format without manual tuning
- Balances performance and accuracy

### 2. Simultaneous Multithreading (SMT)
- Single GPU supports **176 threads**
- Enhanced parallel processing capability

### 3. Full-Stack AI Factory Solution
The Rubin platform features 6 chips co-designed:
- **Vera CPU**: Control plane
- **Rubin GPU**: Compute core
- **NVLink 6**: High-speed GPU-to-GPU interconnect
- **BlueField-4 DPU**: Data center infrastructure processing
- **ConnectX-9 SuperNIC**: Network connectivity
- **Spectrum-6 Ethernet Switch**: Network switching

All components are **co-designed**, eliminating bottlenecks in multi-vendor deployments.

### 4. Dynamo Inference Scheduling Framework
- Supports inference task splitting
- **Prefill stage**: Assigned to Vera CPU / Rubin NVL144 CPX rack
- **Decode stage**: Assigned to Rubin GPU
- Significantly improves inference energy efficiency

### 5. Heterogeneous Collaboration with Groq 3 LPU
- Connected via Spectrum X networking
- Offloads decode tasks for trillion-parameter models to LPU without CUDA code modifications
- Inference task scheduling automatically handled by Dynamo layer
