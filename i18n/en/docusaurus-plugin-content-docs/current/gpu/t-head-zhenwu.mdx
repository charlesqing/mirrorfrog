# Alibaba T-Head Zhenwu PPU

**Vendor**: Alibaba

**Category**: GPU Graphics Processor

**Architecture**: T-Head RISC-V

## Introduction

Alibaba's T-Head Semiconductor subsidiary. Zhenwu 810E PPU (dedicated processor) uses 5nm process, performance comparable to NVIDIA H20. **Officially launched in January 2026, cumulative shipments of 470,000 units serving 400+ customers**, covering Alibaba's Qwen series model training and inference. Hanguang 800 AI inference chip is an earlier product. Approximately 265,000 units shipped in 2025, domestic second tier.
