# d-Matrix Corsair

**Vendor**: d-Matrix (USA)

**Category**: ASIC Dedicated Accelerator

**Architecture**: DCM (Digital Chiplet Matrix)

## Introduction

d-Matrix Corsair is a data center-grade inference platform from US AI inference chip company d-Matrix, based on digital in-memory computing technology, designed specifically for large-scale AI inference workloads. By embedding computation directly into memory arrays, d-Matrix eliminates data movement bottlenecks found in traditional architectures, delivering energy-efficient matrix computation acceleration.
