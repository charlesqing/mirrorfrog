# Microsoft Maia 100

**Vendor**: Microsoft

**Category**: ASIC Dedicated Accelerator

**Architecture**: Maia AI Accelerator

## Introduction

Microsoft Maia 100 is a proprietary AI accelerator optimized for AI training and inference within Azure cloud. Built on a 5nm process, it is deeply integrated with Azure infrastructure to serve AI services such as Microsoft Copilot.

## Specifications

| Model | Compute | Memory | Interface | TDP | Process |
|------|------|-----------|------|-----|------|
| Maia 100 | 1,200 TFLOPS (FP8) | 512MB HBM | Custom high-speed interconnect | 500W | 5nm TSMC |
