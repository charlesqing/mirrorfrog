# TsingMicro Reconfigurable RPU

**Vendor**: TsingMicro

**Category**: ASIC Dedicated Accelerator

**Architecture**: Reconfigurable Computing (CGRA)

## Introduction

TsingMicro, originating from Tsinghua University, focuses on reconfigurable dataflow AI chips (RPU), referred to as the "Transformers of the chip world." Core competitive advantages: high energy efficiency, high flexibility, and low cost. In 2025, it was the only new computing architecture vendor among China's top eight AI accelerator card shippers, with a valuation exceeding 200 billion RMB.

## Code Examples

## Architecture Highlights

- **CGRA (Coarse-Grained Reconfigurable Architecture)**: Coarse-grained reconfigurable architecture, flexibly adapting to different AI algorithms
- **RISC-V Foundation**: Based on RISC-V processor core + CGRA acceleration units
- **Endpoint Positioning**: Low-power edge AI inference scenarios
