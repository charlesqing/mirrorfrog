# Useful Tools

AI accelerator card development and operations involve many external tools — driver lookups, spec comparisons, performance benchmarks, SDK documentation, and more. The following is a curated collection of battle-tested practical resources, covering official portals for major vendors such as NVIDIA, AMD, and Intel, as well as community-maintained spec databases and compute tracking platforms, helping developers and operators work more efficiently.

## Driver Lookup

| Vendor | Tool Link | Description |
|--------|----------|-------------|
| NVIDIA | [Driver Lookup](https://www.nvidia.com/download/index.aspx) | Find and download the latest driver by GPU model and operating system |
| AMD | [Driver Lookup](https://www.amd.com/en/support) | AMD GPU / ROCm driver download center |
| Intel | [Driver Center](https://www.intel.com/content/www/us/en/download-center/home.html) | Intel GPU / oneAPI drivers and software |

## Specs & Compatibility

| Tool | Link | Description |
|------|------|-------------|
| CUDA Support List | [View](https://developer.nvidia.com/cuda-gpus) | NVIDIA official CUDA-accelerated GPU list |
| GPU Spec Database | [TechPowerUp](https://www.techpowerup.com/gpu-specs/) | Detailed specs for virtually all GPUs |
| AI Benchmarks | [OpenBenchmarking](https://openbenchmarking.org/) | Cross-platform performance benchmark results database |

## AI Compute Database

| Tool | Link | Description |
|------|------|-------------|
| Epoch AI Supercomputer Database | [epoch.ai/data/ai-supercomputers](https://epoch.ai/data/ai-supercomputers) | Tracks **700+** global AI training and inference clusters, covering chip type, quantity, power, hosting organization, and other detailed specs. Provides map view, chart view, and table view with filtering and data export. Currently the most comprehensive public database of global AI compute hardware. |
