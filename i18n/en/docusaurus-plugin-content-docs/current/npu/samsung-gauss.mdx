# Samsung Gauss AI

**Vendor**: Samsung

**Category**: NPU Neural Processor

**Architecture**: Samsung NPU Core

## Introduction

Samsung Exynos and Galaxy chip built-in AI processor, including Galaxy AI features and Samsung Gauss large language model. Edge AI inference executed through the Samsung NN (SLIM) framework.

## Specifications

| Model | Compute | Memory | Interface | TDP | Process |
|------|------|-----------|------|-----|------|
| Exynos 2400 | 35 TOPS (INT8) | LPDDR5X (shared) | Integrated SoC | 10W | 4nm LPP+ |
| Exynos 2500 | 45 TOPS (INT8) | LPDDR5X (shared) | Integrated SoC | 10W | 3nm GAA |

### Android

## Code Examples

## Architecture Highlights

- **Samsung NPU Core**: NPU integrated in Exynos SoC, supporting Galaxy AI features
- **Gauss Large Model**: Samsung proprietary multimodal large model, on-device inference + cloud collaboration
