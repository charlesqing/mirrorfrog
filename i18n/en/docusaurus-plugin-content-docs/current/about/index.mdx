# About MirrorFrog

MirrorFrog is an open-source project dedicated to organizing and navigating driver, documentation, and SDK resources for various AI accelerator chips.

## Project Motivation

AI compute card drivers and documentation are scattered across different vendor pages with multiple versions and deep navigation paths, making them very inconvenient to find. MirrorFrog centralizes this information to help AI developers and operators quickly locate what they need.

## Data Sources

Data is sourced from publicly available information on vendor websites and developer centers, curated and maintained manually. We strive to ensure accuracy and timeliness but assume no liability for any issues arising from the use of this site's information.
