# AMD Instinct MI325X (CDNA 3 Refresh)

## Overview

The AMD Instinct MI325X launched in H2 2024 as a memory upgrade over the MI300X. Memory was upgraded from 192GB HBM3 to **256GB HBM3e**, and bandwidth increased from 5.3 TB/s to **6.48 TB/s**. It directly competes with the NVIDIA H200.

## Core Specifications

| Item | Specification |
|------|------|
| **Architecture** | CDNA 3 |
| **Memory** | **256 GB HBM3e** |
| **Memory Bandwidth** | **6.48 TB/s** |
| **FP16 Matrix** | 1,307 TFLOPS (same as MI300X) |
| **FP8 Matrix** | 2,614 TFLOPS |
| **TDP** | 750 W |
| **Form Factor** | OAM |

## MI300X vs MI325X vs H200

| Metric | MI300X | MI325X | H200 |
|------|--------|--------|------|
| Memory | 192 GB | **256 GB** | 141 GB |

| Memory Type | HBM3 | HBM3e | HBM3e |
| FP8 Compute | 2,614 TFLOPS | 2,614 TFLOPS | 3,958 TFLOPS |
