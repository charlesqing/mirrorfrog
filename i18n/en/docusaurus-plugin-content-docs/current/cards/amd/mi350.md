# AMD Instinct MI350X / MI355X (CDNA 4)

## Overview

The AMD Instinct MI350 series, launched on **June 12, 2025**, is AMD's latest flagship AI accelerator, based on the **CDNA 4 architecture**. It features **288GB HBM3e** memory, **8 TB/s** bandwidth, and up to **2.5 PFLOPS FP16** compute. The MI350 introduces native **MXFP4 and MXFP6** data type support, targeting NVIDIA Blackwell.

## MI350 vs Blackwell Comparison

| Metric | MI355X | B200 | GB200 (186GB) |
|------|--------|------|---------------|
| Memory | **288 GB** | 192 GB | 186 GB |
| Bandwidth | **8 TB/s** | 8 TB/s | 8 TB/s |
| FP8 Compute | 10.1 PFLOPS (MXFP6) | 9 PFLOPS | 9 PFLOPS |
| FP4 Support | ✓ MXFP4 | ✓ Native | ✓ Native |

**Key difference**: MI355X has more memory (+50%), while B200 has higher FP4 compute (18 PFLOPS vs MI355X 10.1 PFLOPS).
