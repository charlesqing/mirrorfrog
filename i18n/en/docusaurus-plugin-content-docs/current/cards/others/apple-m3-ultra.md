# Apple M3 Ultra (256GB UMA, 72 TOPS)

## Overview

**Apple M3 Ultra** is Apple Silicon's **3rd-generation Ultra flagship**, released **2023-12**. It merges two M3 Max dies via **UltraFusion 2.0**, delivering a **32-core CPU** (24P+8E), **80-core GPU**, unified memory up to **256GB LPDDR5**, **800 GB/s bandwidth**, and **72 TOPS Neural Engine** -- double the M2 Ultra's Neural Engine compute.

## Core Specifications

| Item | Parameter |
|------|-----------|
| **Architecture** | Apple Silicon (M3 Max x2, UltraFusion 2.0) |

| **GPU Cores** | 80 |
| **Neural Engine** | 32-core, 72 TOPS |
