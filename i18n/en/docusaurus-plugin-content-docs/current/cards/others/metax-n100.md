# MetaX XiSi N100

> MetaX's first AI inference GPU, equipped with MXN100 heterogeneous GPGPU processor, mass-produced in June 2023, INT8 compute 160 TOPS, targeting cloud data center AI inference scenarios.

---

## Technical Highlights

- **MXN100 architecture**: MetaX self-developed heterogeneous GPGPU processor, optimized for AI inference, supporting mixed-precision computing
- **High-density video processing**: Supports 128-channel encoding and 96-channel decoding, compatible with HEVC, H.264, AV1, AVS2 and other video formats, up to 8K resolution support
- **MXMACA software stack**: Companion self-developed software stack, supporting various mainstream AI frameworks, computer vision processing and multimedia processing frameworks
- **HBM2E memory**: Uses high-bandwidth HBM2E memory, meeting memory bandwidth requirements for large language model inference
- **Mass production achieved**: Announced mass production in June 2023, applied in security, smart city and other fields

---

## Product Positioning

XiSi N100 is MetaX's first AI inference GPU, targeting NVIDIA L4/T4 inference cards, focusing on cloud AI inference scenarios. As the inference-specialized product in MetaX's product matrix, N100 complements XiYun C series (training-inference integrated).

---

## Application Scenarios

- Smart city/security AI inference (video analytics)
- Cloud CV/NLP inference services
- Intelligent video processing (transcoding, analytics)
- Edge inference servers
- Large model inference acceleration (INT8 quantization)
