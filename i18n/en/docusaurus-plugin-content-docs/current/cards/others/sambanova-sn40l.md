# SambaNova SN40L

## Product Overview

SambaNova SN40L is an AI accelerator based on the **Reconfigurable Dataflow Unit (RDU)** architecture — it is **not a traditional instruction-based architecture**. The SN40L offers a full **8-node system** (SN40L-8), suitable for enterprise-grade LLM deployment.

## Core Specifications

| Item | Spec |
|------|------|
| **Architecture** | RDU (Reconfigurable Dataflow) |
| **Process** | TSMC 7nm |
| **Memory** | 64 GB HBM3 |
| **FP32 Compute (estimated)** | 100 TFLOPS |
| **INT8 Compute (estimated)** | 200 TOPS |
| **System** | SN40L-8 (8 nodes) |
| **Interconnect** | SambaNova proprietary (Coherent Memory) |
