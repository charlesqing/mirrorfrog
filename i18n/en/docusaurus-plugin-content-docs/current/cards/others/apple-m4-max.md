# Apple M4 Max (128GB UMA, 38 TOPS NE)

## Overview

**Apple M4 Max** is Apple Silicon's **4th-generation Max chip**, released **2024-10** for the **MacBook Pro 14"/16"** and **Mac Studio**. Built on **TSMC 3nm N3E** (2nd-gen 3nm), it features a **16-core CPU** (12P+4E), **40-core GPU**, **128GB LPDDR5X unified memory**, **546 GB/s bandwidth** (+36% vs M3 Max), and **38 TOPS Neural Engine** (2.1x M3 Max). Designed for **Apple Intelligence** and professional workloads.
