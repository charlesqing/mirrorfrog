# Apple M4 Pro (64GB UMA, 38 TOPS NE)

## Overview

**Apple M4 Pro** is Apple Silicon's **4th-generation Pro chip**, released **2024-10** for the **Mac mini** and **MacBook Pro 14"**. Built on **TSMC 3nm N3E**, it features a **14-core CPU** (10P+4E), **20-core GPU**, **64GB LPDDR5X unified memory**, **546 GB/s bandwidth** (same as M4 Max), and **38 TOPS Neural Engine**. Represents a major leap from M3 Pro.
