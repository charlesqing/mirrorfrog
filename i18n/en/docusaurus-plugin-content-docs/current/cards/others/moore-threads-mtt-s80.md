# Moore Threads MTT S80

> Moore Threads' first consumer-grade gaming graphics card, equipped with full "Chunxiao" chip, 4096 MUSA cores, released November 2023, representative work of domestic gaming graphics cards.

---

## Technical Highlights

- **Chunxiao chip**: Moore Threads' second-generation GPU chip, 7nm process, 4096 MUSA unified computing cores
- **PCIe 5.0**: Industry's first consumer-grade graphics card supporting PCIe 5.0, bidirectional bandwidth up to 128GB/s
- **Full-function GPU**: Simultaneously supports graphics rendering, AI computing, and video encoding/decoding, based on the same MUSA architecture
- **DirectX support**: Supports DirectX 11/12, can run mainstream 3D games
- **AI inference capability**: FP16 compute 57.6 TFLOPS, can accelerate local AI inference (such as LLM inference)

---

## Product Positioning

MTT S80 is Moore Threads' first gaming graphics card targeting the consumer market, positioned as NVIDIA RTX 4060 level product. As the representative of "domestic gaming graphics cards", S80 has unique value in domestic substitution and local AI inference scenarios.

---

## Application Scenarios

- Domestic 3A gaming (based on DirectX 11/12)
- Local AI large model inference (LLaMA, ChatGLM, etc.)
- 8K video playback and processing
- Graphics rendering and CAD
- Domestic operating systems (Unity UOS, Kylin) graphics acceleration
