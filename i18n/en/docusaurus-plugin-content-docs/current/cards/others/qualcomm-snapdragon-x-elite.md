# Qualcomm Snapdragon X Elite (Oryon 12-core NPU 45 TOPS)

## Product Overview

**Qualcomm Snapdragon X Elite** is Qualcomm's **ARM architecture PC chip** released at the **2023-10 Snapdragon Summit**, **4nm TSMC** process, **12-core Qualcomm Oryon CPU** @ 3.8 GHz (single/dual-core boost to **4.3 GHz**), **Adreno GPU** (up to 4.6 TFLOPs), **Hexagon NPU 45 TOPS** (**the highest laptop NPU**), **LPDDR5x 8448 MT/s 64GB memory**, **135 GB/s bandwidth**. Total AI compute 75 TOPS. **Microsoft Copilot+ PC certified** (Recall, Live Captions, Cocreator 3 exclusive AI features). The **first** ARM Windows chip that can challenge Apple Silicon M2/M3 across battery life, performance, and AI.

## Key Features

- **4nm TSMC** process
- **12-core Qualcomm Oryon CPU** (custom ARM architecture, original Apple Silicon team design)
- **3.8 GHz base / 4.2-4.3 GHz Boost** (strongest single-core ARM CPU)
- **42 MB Total Cache**
- **Adreno GPU 4.6 TFLOPs** (strongest integrated GPU ARM laptop)
- **Hexagon NPU 45 TOPS** (strongest laptop NPU in industry)
- **Micro NPU + Sensing Hub** (always-on low-power AI, 0.1W class)
- **75 TOPS AI Total**
- **LPDDR5x 64GB** memory, **135 GB/s** bandwidth
- **Wi-Fi 7**, **Bluetooth 5.4**, **5G mmWave** (optional)
- **Copilot+ PC certified** (Recall, Live Captions, Cocreator)
- **Multi-day battery life** (15-20+ hours)
- **AV1 hardware encode/decode** (4K120 decoding)
