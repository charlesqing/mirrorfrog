# Apple M4 Ultra (Estimated, 2025 Q4)

## Overview

**Apple M4 Ultra** is Apple Silicon's **projected 4th-generation Ultra flagship**, expected in **late 2025**. Based on merging two M4 Max dies via **UltraFusion 2.0**, it is projected to deliver a **32-core CPU** (24P+8E), **80-core GPU**, **256GB LPDDR5X**, **819 GB/s bandwidth**, and **76 TOPS Neural Engine**.

## Core Specifications (Estimated)

| Item | Parameter |
|------|-----------|
| **Architecture** | Apple Silicon (M4 Max x2, UltraFusion 2.0) |
| **Process** | TSMC 3nm N3E |
| **CPU Cores** | 32 (24P + 8E) |
| **GPU Cores** | 80 |
| **Neural Engine** | 32-core, 76 TOPS (estimated) |
| **Unified Memory** | 64GB - 256GB LPDDR5X |
| **Memory Bandwidth** | 819 GB/s (estimated) |
| **UltraFusion** | 2.5 TB/s |

| **Projected Launch** | 2025 Q4 |
