# Apple M5 Ultra (Estimated, 2026 H2)

## Overview

**Apple M5 Ultra** is the projected **5th-generation Ultra flagship**, rumored for **late 2026**. Expected to be built on **TSMC 2nm**, it represents a major architectural leap with **40 CPU cores** (24P+16E), **96-120 GPU cores**, up to **384GB LPDDR6** unified memory, **~1 TB/s bandwidth**, and **~120 TOPS Neural Engine**.
