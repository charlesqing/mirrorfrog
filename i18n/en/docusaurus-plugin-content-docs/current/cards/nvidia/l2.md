# NVIDIA L2 (Entry-Level Ada Inference)

## Overview

**NVIDIA L2** is an **Ada Lovelace-based, export-compliant entry inference card built for the China market** (part of the same compliant lineup as the H20 and L20), positioned below the L4. With 24GB GDDR6 ECC memory in a **single-slot, half-height half-length (LP)** form factor, it targets space- and power-sensitive deployments.

Aimed at **edge servers, telecom operators, retail**, and other low-power AI inference scenarios.

## L2 vs L4 vs T4 Comparison

| Metric | L2 | L4 | T4 |
|------|-----|-----|-----|
| Architecture | Ada | Ada | Turing |
| CUDA Cores | 4,608 | 7,680 | 2,560 |
| Memory | 24GB GDDR6 | 24GB GDDR6 | 16GB GDDR6 |
| Bandwidth | 300 GB/s | 300 GB/s | 320 GB/s |
| FP8 Tensor (sparse) | 386 TFLOPS | 485 TFLOPS | N/A |
| TDP | Not disclosed | 72W | 70W |
| Form Factor | Single-slot LP | Single-slot | Single-slot |

> The L2 delivers about 80% of the L4's sparse FP8 compute at identical memory bandwidth; its differentiation is a lower price and a low-profile, power-efficient form factor.

## Use Cases

- ✅ **Edge server AI inference** (5G MEC)
- ✅ Telecom vRAN + AI convergence
- ✅ Retail edge AI (video analytics)
- ✅ Embedded data centers
- ❌ Large model inference (use L40S/H100)
- ❌ Training (no NVLink; poor multi-card scaling)
