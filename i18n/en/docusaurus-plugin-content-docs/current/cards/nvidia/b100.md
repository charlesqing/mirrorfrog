# NVIDIA B100 (Blackwell)

## Product Overview

The NVIDIA B100, released in 2024, is the entry-level data center GPU of the Blackwell architecture. It uses a **dual-die** design interconnected via a 10 TB/s NV-HBI internal bridge. With a relatively modest 700W TDP, the B100 can drop directly into existing H100/H200 server baseboards, making it a top choice for cloud providers deploying Blackwell at scale.

> **Important**: The B100 was largely surpassed by the B200 in actual 2024–2025 deployments. Many cloud providers (e.g., Modal, CoreWeave) skipped the B100 entirely.

## Key Features

- **5th Gen Tensor Cores**: Native FP4 / FP6 precision support
- **2nd Gen Transformer Engine**: Automatic FP4 precision conversion
- **NVLink 5.0**: 1.8 TB/s GPU-to-GPU interconnect
- **RAS Engine**: Reliability, Availability, Serviceability
- **Confidential Computing**: Hardware-level TEE support
