# NVIDIA RTX Pro 5000 Blackwell

## Product Overview

The **NVIDIA RTX Pro 5000 Blackwell** is a professional workstation GPU launched by NVIDIA in 2025 based on the **Blackwell architecture**, a trimmed-down version of the RTX Pro 6000 Blackwell. With **48GB GDDR7 ECC memory** (plus a 72GB version) and a **300W TDP**, it retains 5th-generation Tensor Cores and FP4 inference capability — a cost-effective workstation card for **local LLM development and professional graphics**.

**Strategic position**: Between the RTX Pro 6000 (96GB) and the consumer RTX 5090 (32GB), the RTX Pro 5000 fills the mid-range AI workstation gap with **48GB ECC memory + professional drivers**, balancing memory capacity and cost.
