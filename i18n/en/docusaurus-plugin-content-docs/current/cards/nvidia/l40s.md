# NVIDIA L40S (Ada Lovelace)

## Product Overview

The NVIDIA L40S, released in 2023, is a **versatile data center GPU** spanning AI inference, 3D rendering (Omniverse), video transcoding, and scientific computing. Based on the full **Ada Lovelace AD102** die, it offers 48GB GDDR6 ECC memory, **733 TFLOPS FP8** compute, and a 350W TDP. The L40S replaces the L40 and is also commonly used for virtualization (vGPU).

## Core Specifications

| Parameter | Value |
|-----------|-------|
| **Architecture** | Ada Lovelace AD102 |
| **Process Node** | TSMC 4N |
| **Memory** | 48 GB GDDR6 ECC |
| **Memory Bandwidth** | 864 GB/s |
| **CUDA Cores** | 18,176 |
| **Tensor Cores** | 568 (4th Gen) |
| **FP32** | 91.6 TFLOPS |
| **FP8 Tensor Core** | 733 TFLOPS (sparse) |
| **INT8 Tensor Core** | 1,466 TOPS |
| **TDP** | 350 W |
| **PCIe** | Gen 4 x16 |
| **Video Codec** | 3× NVENC (AV1) + 3× NVDEC (AV1) |
| **vGPU** | Supported |
