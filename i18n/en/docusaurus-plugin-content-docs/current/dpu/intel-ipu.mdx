# Intel IPU (Infrastructure)

**Vendor**: Intel

**Category**: DPU Data Processing Unit

**Architecture**: Intel IPU (N6000)

## Introduction

Intel IPU (Infrastructure Processing Unit) is used for data center infrastructure offloading, similar to a DPU. The E2000 series uses Agilex FPGA architecture, supporting NVMe over Fabrics, virtIO, encryption offload, and more.

## Specifications

| Model | Compute | Memory | Interface | TDP | Process |
|------|------|-----------|------|-----|------|
| IPU N6000 | 200 Gbps Networking | 16GB DDR5 | PCIe 5.0 | 30W | Intel 7 |
| IPU E2100 | 100 Gbps Networking | 8GB DDR4 | PCIe 4.0 | 20W | Intel 7 |

## Architecture Highlights

- **Intel IPU Architecture**: FPGA/ASIC-based infrastructure processing unit, aimed at cloud data center network virtualization
- **SR-IOV**: Standard PCIe virtualization interface, integrating with cloud management platforms
