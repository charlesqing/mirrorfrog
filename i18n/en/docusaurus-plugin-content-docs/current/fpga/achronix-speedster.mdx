# Achronix Speedster FPGA

**Vendor**: Achronix

**Category**: FPGA Field-Programmable Gate Array

**Architecture**: Speedster7t

## Introduction

Achronix Speedster7t FPGA uses 7nm process technology, optimized for high-bandwidth AI inference. It features built-in Machine Learning Processor (MLP) blocks supporting tensor computation acceleration, suitable for data center AI inference scenarios.

## Specifications

| Model | Compute | Memory | Interface | TDP | Process |
|------|------|-----------|------|-----|------|
| Speedster7t AC7t1500 | 80 TOPS (INT8) | External DDR4 | PCIe Gen4 x16 | 120W | 7nm (TSMC) |
| Speedster7t AC7t600 | 40 TOPS (INT8) | External DDR4 | PCIe Gen4 x8 | 60W | 7nm (TSMC) |
