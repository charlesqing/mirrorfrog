## FAQ

### What are the main differences between NVIDIA RTX 4090 and NVIDIA RTX 5090 (Blackwell 消费级旗舰)?

The core difference is architecture and compute density: NVIDIA RTX 4090 uses Ada Lovelace AD102, FP8 ~2,642 TFLOPS, memory 24 GB GDDR6X; NVIDIA RTX 5090 (Blackwell 消费级旗舰) uses Blackwell (GB202), FP8 ~838 TFLOPS, memory 32 GB GDDR7. See the comparison table above.

### What is the TDP (power) of NVIDIA RTX 4090?

NVIDIA RTX 4090 has a TDP of 450 W; actual whole-system power also includes board, fans, and PUE.

### Which is better for large-model training / inference?

Training values memory capacity, bandwidth, and multi-card interconnect; inference values single-card throughput and power efficiency. Combine the "Key Differences" and "Selection Advice" above with your batch size, model size, and SLA.

### How much do NVIDIA RTX 4090 and NVIDIA RTX 5090 (Blackwell 消费级旗舰) differ in memory capacity?

NVIDIA RTX 4090 is 24 GB GDDR6X, NVIDIA RTX 5090 (Blackwell 消费级旗舰) is 32 GB GDDR7; the gap directly affects loadable model size and context length.
