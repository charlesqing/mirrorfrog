## FAQ

### What are the main differences between AMD Instinct MI300X and AMD Instinct MI325X?

The core difference is architecture and compute density: AMD Instinct MI300X uses CDNA 3, FP8 ~No public FP8 data, memory 192 GB HBM3; AMD Instinct MI325X uses CDNA 3, FP8 ~No public FP8 data, memory 256 GB HBM3e. See the comparison table above.

### What is the TDP (power) of AMD Instinct MI300X?

AMD Instinct MI300X has a TDP of 750 W; actual whole-system power also includes board, fans, and PUE.

### Which is better for large-model training / inference?

Training values memory capacity, bandwidth, and multi-card interconnect; inference values single-card throughput and power efficiency. Combine the "Key Differences" and "Selection Advice" above with your batch size, model size, and SLA.

### How much do AMD Instinct MI300X and AMD Instinct MI325X differ in memory capacity?

AMD Instinct MI300X is 192 GB HBM3, AMD Instinct MI325X is 256 GB HBM3e; the gap directly affects loadable model size and context length.
