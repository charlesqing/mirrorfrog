## 方案 C 排序：重要性 + 时效性综合算法
为热门芯片列表引入数据驱动的综合排序：

### 规则
- 厂商权重：NVIDIA 1.0 / AMD 0.9 / Google 0.85 / 华为 0.8 / Intel 0.75 / Cerebras 0.7
- 类别权重：训练 1.0 / 推理 0.8 / 消费 0.6 / 边缘 0.5 / 晶圆 0.4 / 神经形态 0.3
- 时效性系数：`max(0.3, 0.85 ^ 年龄)`，参考点 2026-01-01
- 综合得分 = 厂商权重 × 类别权重 × 时效性系数
- 同分按 released 日期降序
