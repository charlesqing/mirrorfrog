# 昇腾950智算集群云服务正式商用：9月30日国内上线、11月30日全球商用

> 华为全联接大会2026给出明确时间表：昇腾950智算集群云服务9月30日国内商用、11月30日全球商用，全球首个NPO超节点昇腾960同步亮相。

## HUAWEI CONNECT 2026：商用时间表落定

2026年9月17日，华为全联接大会在上海举行。大会上，华为披露了昇腾950智算集群云服务的商用节奏：9月30日国内商用，11月30日全球商用。从大会披露到国内上线仅半个月，节奏之紧，说明昇腾950超节点的规模化交付已经就绪。

| 关键节点 | 时间/地点 |
| --- | --- |
| 华为全联接大会2026 | 2026年9月17日（上海） |
| 昇腾950智算集群云服务国内商用 | 2026年9月30日 |
| 昇腾950智算集群云服务全球商用 | 2026年11月30日 |

"国内先行、两月后推向全球"的节奏也传递出另一个信号：昇腾不再只盯着国内市场，智算集群云服务将作为中国AI算力方案走出去的载体，参与全球算力供给的竞争。

## 昇腾960超节点：全球首个NPO超节点

同期发布的昇腾960超节点，是全球首个NPO超节点（近封装光学超节点），关键规格如下：

| 指标 | 数值 |
| --- | --- |
| 卡规模 | 4096卡 |
| 算力 | 8 EFLOPS FP8 / 16 EFLOPS FP4 |
| 显存 | 1PB HBM |
| 光互联方案 | 5500个Hi-ONE光引擎，替代4.8万颗800G光模块 |
| 降功耗 | 550kW |
| 可用度 | 99.8% |
| Hi-ONE单引擎传输容量 | 7.2T |

这组数字的核心看点在于光互联的代际切换：用5500个Hi-ONE光引擎替代4.8万颗800G光模块，降低550kW功耗，同时做到99.8%的可用度。NPO（近封装光学）路线在超节点规模下的价值被直观呈现——光模块数量下降一个数量级，意味着故障点、功耗与运维复杂度同步大幅收敛。在4096卡这种规模的系统里，互联可靠性直接决定训练任务的连续性。

## 昇腾950超节点：规模商用与SOTA背书

昇腾950超节点已规模商用1000多套，落地行业覆盖互联网、运营商、金融、教育、医疗、交通、制造等。规模数字之外，更关键的背书是：昇腾950超节点是国内唯一训练出SOTA模型的超节点。

"能训练出SOTA模型"是对训练集群最硬核的检验——它证明的不仅是硬件规格，而是"集群规模+互联效率+软件栈"的组合在大规模训练中真实可用。对于正在选型的行业客户而言，这比任何纸面参数都更有说服力。

## 芯片路线图：960提前就绪，970/980排期明确

华为还更新了昇腾芯片的推进节奏：

- 昇腾960DT较原计划提前三个季度就绪；
- 昇腾960PR提前一个季度就绪；
- 2028年推出昇腾970，2029年推出昇腾980。

"提前就绪"在当前的供应链环境下格外难得——在全球先进制造资源紧张、HBM紧缺的背景下，按时甚至提前交付，本身就是工程与供应链能力的体现。而970/980排期明确到年份，则给生态伙伴与客户提供了可规划的长期预期。

## CANN全面开源：生态数据盘点

软件生态方面，昇腾的进展可以用一组数据概括——CANN已全面开源：

- 外部开发者占比61%，月活跃开发者超5200名；
- 40+模型实现原生训练；
- 支持PyTorch、Triton、vLLM、veRL等90+开源项目；
- 成为PyTorch官网首个中国算力平台。

其中"PyTorch官网首个中国算力平台"具有标志性意义：主流框架的原生适配，意味着开发者迁移成本大幅降低，而61%的外部开发者占比说明社区已经超出华为体系自身，形成外部贡献的正循环。

## 全栈协同：TaiShan 950与OceanStor M900

硬件侧的配套升级同样值得关注。TaiShan 950超节点完成升级：支持4096节点、256TB统一内存池——统一内存池让CPU侧内存资源可以按需调度，与超节点的算力规模相匹配。存储侧，OceanStor M900上下文内存存储提供PB级KV Cache能力，直击大模型推理场景的上下文缓存需求：推理热门场景下，KV Cache的存取效率直接决定吞吐与首字延迟。

芯片（昇腾950/960）、CPU（TaiShan 950）、存储（OceanStor M900）、软件栈（CANN）四层同步演进，华为走的是典型的全栈协同路线。

## 小结

从昇腾950智算集群云服务"9月30日国内、11月30日全球"的商用时间表，到昇腾960超节点"4096卡、8 EFLOPS FP8、16 EFLOPS FP4、1PB HBM、5500个Hi-ONE光引擎"的规格突破，再到昇腾950超节点规模商用1000多套、成为国内唯一训练出SOTA模型的超节点，以及CANN全面开源、外部开发者占比61%的生态进展，华为正以"芯片-超节点-云服务-开源生态"的全栈节奏推进昇腾路线图。昇腾970（2028）、昇腾980（2029）的排期已经明确——昇腾的追赶不再只是单点突破，而是体系化的持续推进。
