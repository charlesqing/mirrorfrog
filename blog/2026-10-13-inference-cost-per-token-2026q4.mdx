# 每百万 token 成本实测框架：2026 年 Q4 价格环境下的自建与 API 选型

> 「每百万 token 多少钱」这个问题，在 2026 年已经失去了单独讨论的意义。2026 年 10 月 8 日的价格快照显示，最便宜的模型输入价已跌到每百万 token 0.05 美元（GPT-5 Nano）到 0.14 美元（DeepSeek V4 Flash）区间，而旗舰模型仍在 4 至 5 美元输入、20 至 25 美元输出。**头部与尾部之间相差约 100 倍**，真正决定账单的不是单价，而是你的计量口径。

---

## 一、2026 年 10 月的价格环境基线

以下是我们核实的公开价格（单位：美元 / 每百万 token），可用于建立四季度预算模型：

| 模型 | 输入 | 输出 | 上下文 | 备注 |
|------|------|------|--------|------|
| GPT-5 Nano | 0.05 | 0.40 | — | 当前最低输入价 |
| Qwen3.8 Flash | 0.09 | 0.28 | — | 聊天场景最省 |
| Gemini 2.5 Flash-Lite | 0.10 | 0.40 | — | 精确 token 计数 |
| DeepSeek V4 Flash | 0.14 | 0.28 | 128K | 输入侧另有峰谷价 |
| GLM-5.3 Flash | 0.15 | 0.50 | 128K | — |
| Qwen3.6-Plus | 0.50 | 3.00 | 1M | 超 256K 输入翻至 2.00 / 6.00 |
| Gemini 3.7 Flash | 0.75 | 3.75 | 1M | 促销价，2026-12-31 后翻倍 |
| Claude Opus 5 | 5.00 | 25.00 | 1M | 8 月定价至今未变 |

**四个必须注意的口径陷阱：**

1. **促销有到期日。** Gemini 3.7 Flash 的 0.75 / 3.75 是促销价，官方标注 2026 年 12 月 31 日后恢复至 1.50 / 7.50。Qwen3.6-Plus 的国际版价格在输入超过 256K 后跳到 2.00 / 6.00。**用促销价做全年预算，等于给自己埋一个 2 倍的账。**
2. **峰谷定价真实存在。** DeepSeek V4 Flash 的官方价为离峰 0.22 / 0.66、峰段 0.44 / 1.32，峰段为 UTC 工作日的两个时段。如果你把离线批处理挪到离峰时段，同一批任务能省一半。
3. **缓存命中价差三个数量级。** DeepSeek V4 Flash 缓存命中输入低至每百万 0.007 美元。RAG 或多轮对话场景里，缓存命中率每提升 10 个百分点，输入成本下降约一个量级。
4. **输出单价通常是输入的 3 至 5 倍。** 输入重的负载（翻译、文档重读）与输出重的负载（代码生成、长摘要）必须分开建模。

## 二、1 亿 token 月预算的真实账单

取一个典型负载：1 亿输入 token + 1000 万输出 token。按上表单价估算：

| 模型 | 月账单估算 | 说明 |
|------|-----------|------|
| DeepSeek V4 Flash | 约 28.60 美元（离峰） | 峰段则约 57.20 美元 |
| Qwen3.6-Plus | 约 80 美元 | 前提是多数请求输入不超 256K，否则约 260 美元 |
| Gemini 3.7 Flash | 约 112.50 美元 | 促销期内，12 月底后约 225 美元 |
| GPT-5.6 Sol | 约 600 美元 | 短上下文标准档 |
| Claude Opus 5 | 约 750 美元 | 1M 上下文 + 默认开启思考 |

**同一份工作，账单差 26 倍。** 但这里有个陷阱比价差本身更重要：一个 0.14 美元的模型如果需要三次重试才给出正确结果，实际成本是 0.42 美元——比一次成功的 0.50 美元模型更贵。**重试率必须计入单 token 成本。**

## 三、什么规模开始值得自建

自建的门槛取决于你的月 token 量。公开分析给出的经验阈值是：**70B 级模型在每月 5 亿至 8 亿 token 以上时，自建的推理开支相比前沿 API 标价可降低 65% 至 80%**。

而自建的另一条参考线来自芯片视角。联想 2026 年的生成式 AI TCO 研究给出：自托管 Llama 70B 的每百万 token 成本约 0.11 美元，而同类托管 API 约 2.00 美元，**相差约一个数量级**；对一台 Blackwell 级系统连续运行对标按需云价，五年节省超过 500 万美元，降幅 83.8%。

但这些数字有一个共同前提：**硬件不闲着**。该研究测算的盈亏平衡点，在对标按需云价时不到四个月，在对标深度折扣的多年期预留合约时则拉长到九到十个月。

## 四、实测框架：四步算出你的真实单位成本

| 步骤 | 做什么 | 关键变量 |
|------|--------|----------|
| 1 | 统计真实输入输出比 | 通常在 5:1 到 20:1 之间，别用 1:1 |
| 2 | 测算缓存命中率 | 决定输入侧实际单价 |
| 3 | 折算重试与失败成本 | 重试率乘以单次成本 |
| 4 | 与自建摊销对照 | 自建月均 token 除以单卡月处理量 |

**第 4 步的实操做法**：拿一台具体卡型（比如 8 卡 H200 整机，月租 5 万至 6.6 万元；或 B200 云端按需约 5.98 至 8.60 美元/卡时），用你实测的吞吐（token/s）换算出月产出 token 总数，再除以月成本，得到自建的每百万 token 成本。**这个数字必须用你自己的实测吞吐，不能用厂商标称峰值。**

## 五、Q4 选型清单

- **默认档**：把 DeepSeek V4 Flash 或 Qwen3.8 Flash 作为新功能的第一落点，前者综合性价比最优，后者输入最省。
- **离线档**：批处理、评测、数据清洗全部挪到离峰窗口，并接缓存，DeepSeek V4 Flash 缓存命中输入低至 0.007 美元/百万。
- **旗舰档**：只在具体任务被证明需要时升级。GPT-5.6 Luna 被称为「旗舰 90% 质量、2% 价格」的位置，Claude Opus 5 与 GPT-5.6 Sol 的差价买的是能力上限而非平均表现。
- **自建评估档**：月 token 量稳定在 5 亿以上、且负载 7×24 有基线，才启动自建建模。
- **预算纪律**：所有促销价按到期后的价格做全年预算，把峰值定价按峰段价做压测。

> **一句话总结**：2026 年 Q4 的 token 成本优化，重点已经从「找便宜的模型」转向「选对计量口径」——缓存、峰谷、重试率、促销到期日，这四项加起来的量级远超模型之间的价差。
