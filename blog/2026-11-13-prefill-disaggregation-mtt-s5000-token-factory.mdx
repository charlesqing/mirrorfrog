大模型推理是两段活，却长期塞在同一批卡里跑。Prefill 要把整段输入一口气算完，吃算力；Decode 一个 token 一个 token 往外吐，吃显存带宽。硬塞在一种硬件上，两头都难喂饱。

11 月初 2026 人工智能+大会上，摩尔线程拉上趋境科技和智谱发了个方案，把这两段拆开：S5000 负责 Prefill，靠它的高密度算力和原生 FP8；显存带宽更大的算力接 Decode；趋境做 KVCache 跨设备流转，把两头的资源拼成一个能对外计费的服务。官方叫「国产异构推理高品质 AI Token 工厂」，名字挺长，做的事情其实就这句。

我关心的是它给了生产环境的数，而不是又一轮跑分。广州日报大洋网和三易生活转述的实测：平均生成速度超过 50 TPS，KV Cache 命中率超过 90%，稳定性 99.9%；由 3 至 4 台 S5000 组成的 Prefill 池，在同等服务标准下，输入 Token 处理性价比超过国际先进算力方案。方案称已在生产环境全面使用，承载头部模型企业的超大参数模型和高并发流量。

「性价比超过」这句得拆着看。它没给对比机型、并发数、序列长度、命中率口径，也没给每 Token 成本的具体数值。50 TPS、90%、99.9% 是整套方案在真实流量下的指标，不是单卡吞吐，不能拿来反推一张卡能跑多少。厂商给的是结论，分母留在自己手里。

但方向我认。推理一旦按 Token 计费，采购看的就不再是单卡峰值，而是单位硬件支出能交付多少确定性的输出。把 Prefill 拆成可独立供给、独立计费、独立优化的资源池，本质是在给这件事定价。前一阵写 [国产超节点这一年](/blog/supernode-year-one-2026-csc-research) 时记过同一批展会的另一面：超节点正从训练集群规格变成按 Token 卖的推理产能，华为和中移动那边的说法也对得上。11 月 6 日中国移动在移动网络大会上说，未来两年智算能力连续翻番，今年开工 3 个吉瓦级计算园区、明年再建 2 个，2027 年算力投资 1000 亿元以上。买家开始按产能算账，卖家的方案自然会往这个形状长。

对选型的人来说，能提的要求很具体：让厂商在指定的并发、序列长度和命中率下给全栈吞吐和每 Token 成本，别只看 50 TPS。[MTT S5000 卡片](/docs/cards/others/moore-threads-mtt-s5000) 补了这套方案与口径边界，规格表没动；要比单卡参数去 [全库对比表](/docs/comparison)，但那张表回答不了这套方案值不值。

> 口径：广州日报大洋网（2026-11-04）、三易生活（2026-11-06）转述厂商发布；中国移动数据来自 2026 移动网络大会媒体报道。方案级指标未附并发、模型、序列长度与集群规模，无可折算的单卡数值。
