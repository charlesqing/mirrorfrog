# 2026：国产超节点放量元年

> 中信建投 10 月 21 日研报给国产超节点下了一个明确判断：行业已**由方案验证正式进入规模化交付阶段**，2026 年是放量元年。这份研报的价值在于把「超节点为什么赢」讲清楚了——不是营销概念，是六个维度的工程优势。

## 一、超节点 vs 传统集群：六个维度

| 维度 | 传统八卡服务器集群 | 超节点 |
|---|---|---|
| 算力利用率 | 跨节点通信损耗大，闲置率偏高 | 柜内完成高频通信，利用率显著提升 |
| 互联带宽 | 受网卡/交换机瓶颈 | 柜内高带宽 P2P，统一内存编址 |
| 吞吐与时延 | All-to-All 跨节点、微秒级以上 | 单跳 ~100 纳秒级（如 IXL144） |
| MoE 适配 | 专家并行通信是灾难 | 专家权重/激活留在柜内 |
| 单卡有效吞吐 | 名义算力打折严重 | 接近名义值 |
| 扩展方式 | 加机器、重调优 | 柜内 Scale-up + 柜间 Scale-out |

一句话总结：**超节点用系统工程能力，把大模型训练推理中最贵的「跨节点通信」尽可能消灭在柜内**。

## 二、演进路线对照

- **英伟达**：GB200/GB300 NVL72 → Vera Rubin NVL144 → NVL288 → NVL576，更大的 NVLink 域、正交背板、柜间光互联
- **华为**：Atlas 950 / 960 SuperPoD，业界首个 NPO 光引擎超节点，单节点 4096 卡
- **国产梯队**：阿里磐久 AL128/AL144、天数 IXL144、昆仑芯 32/64 卡（率先量产）、沐曦曦景 S600、燧原 ESL64-O

## 三、产业链受益顺序

研报给出的受益传导链（按先后）：

1. **服务器整机、交换芯片、交换机、连接器**——超节点渗透率提升的第一波
2. **PCB、液冷、电源、CPU**——随整机柜形态放量
3. **国产算力芯片**——系统级需求带动芯片采购

这与「机柜即产品」的判断一致：竞争单位放大后，瓶颈与利润沿供应链逐环节扩散。

## 四、需求侧的两个数据锚点

- IDC：2026 年中国智能算力规模预计 **2576.5 EFLOPS**，同比增长 87.9%（智能体拉陡需求曲线）
- 工信部：截至 2026 年 6 月底全国智能算力 2185 EFLOPS，算力设施整体上架率 **71.4%**

上架率 71.4% 意味着存量机房还有约三成余量——这正是天数 IXL144 主打「适配现有机房」、华为 Atlas 860 主打「风冷、无需液冷改造」的市场基础：**超节点的下一个战场是部署友好度**。



## 2026-11-08 补记：展会给出了「按什么卖」的答案

11 月 5 至 7 日 2026 移动网络大会（广州）上，超节点密集以「Token 工厂」的形态出现。华为展出昇腾 950 超节点，256TB 统一内存编址、1024 块昇腾 950、RTT 3μs，明确支持内部 AI 自用、算卡租赁、Token 服务三种商业模式；新华三 H3C UniPoD S80000 单柜容纳 32 或 64 张加速卡，全系覆盖 32 至 1024 卡、最高可扩展到 16384 卡；摩尔线程展出夸娥万卡训练平台与面向推理的异构 Token 工厂，用 PD 分离、异构 KV Cache 转换与异构计算融合提高单位资源有效 Token 产出；后摩智能则以 M50 对应「端侧免费 Token 工厂」。

中信建投研报判断的是「行业由方案验证进入规模化交付」，展会补上的是另一半：规模化交付之后按什么计价。这给本文第四节那个 71.4% 上架率加了一层含义——卖卡只需交付到机房，卖 Token 要等机房真跑起来才能产生收入，存量机房的三成余量因此不只是部署友好度问题，也是这些方案能否按期产生现金的前置条件。

我的判断是：按 Token 计价对采购方是好事，它把比较口径从「一台超节点多少钱」推向「每百万 Token 多少钱」，与本站 [TCO 计算器](/docs/tco-calculator) 里每 token 成本的逻辑一致。但目前没有一家公布统一的测量条件（模型、并发、序列长度、KV Cache 命中率），这些数字暂时无法横向比价。要真正可比，得先要求厂商在同一组负载条件下给出有效 Token 产出与整栈功耗，而不是只给统一内存编址容量与卡数。

> 口径：展会展示与厂商方案描述，1024 卡 / 256TB / 3μs 等为系统级配置，非单芯片规格；无第三方实测吞吐或每 Token 成本。

## 2026-11-13 更新：1024 卡超节点有了官方口径

11 月 2 日乌镇世界互联网大会领先科技奖，「昇腾950超节点」获奖。华为昇腾计算产品线总裁张迪煊在颁奖礼现场（央视网直播实录、光明网）给了一组比展会材料更完整的数：单节点 1024 张 NPU、1300 余颗灵衢互联芯片、4000 余只光模块，统一内存编址；1024 卡超节点训练算力利用率 45%，称为业界 1.8 倍；推理时延低至 5 毫秒；40 多个大模型已在昇腾完成原生预训练；昇腾系列超节点已落地 1000 多套，覆盖互联网、运营商、金融、教育、能源。后续路线写的是「超节点 + 超集群」。

本文此前列的 1024 卡 / 256TB / 3μs 来自 11 月广州移动网络大会的展会口径，两组数可以对照，但都出自厂商，没有第三方实测。真正新增的是「1000 多套」这个交付量级：研报里说的放量元年，第一次有了可引用的落地数字，尽管没拆分行业，也没给验收口径。

买这类系统时我会盯 45% 这个数的条件。算力利用率跟模型结构、并行策略、序列长度、故障恢复都绑在一起，厂商给的是某一套配置下的结果，换一套模型未必还是 1.8 倍。合同里该要的是指定并发与序列长度下的实测吞吐和每 Token 成本，而不是统一内存编址容量。

> 口径：颁奖礼现场发言与官方媒体报道；45%、5 毫秒、1000 多套、1.8 倍均为华为口径，未附第三方实测或分行业交付明细。
