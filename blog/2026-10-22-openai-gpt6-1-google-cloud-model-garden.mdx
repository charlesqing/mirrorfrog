# OpenAI 模型上架 Google Cloud：AI 分销进入「Marketplace 抽成」时代

> 10 月 21 日，OpenAI 宣布其前沿模型（含 GPT-6.1 Astra、Sol、Luna）与 Codex 编码智能体进入谷歌云 Model Garden，经 Google Cloud Marketplace 结算，企业可用已有 GCP 消费承诺抵扣。这是 OpenAI 前沿模型首次上架第三大超算云的店面。

## 一、交易结构

| 要素 | 内容 |
|---|---|
| 上架内容 | GPT-6 / 6.1（Astra、Sol、Luna）+ Codex 智能体工作流 |
| 运行位置 | **完全跑在谷歌基础设施上**，受 Google Cloud 访问控制与数据治理约束 |
| 结算 | Google Cloud Marketplace，谷歌抽成 **1.5%（大额私享报价）- 3%（标准）** |
| 抵扣 | 企业可用已签的 GCP 消费承诺支付 |
| GA | 未来数周，先企业私测 |
| 微软地位 | 仍为主要云伙伴、Azure 首发权、2500 亿美元承诺至 2032 不变 |

## 二、谁赚谁亏

- **OpenAI**：收入 ~500 亿美元年化（9 月底口径），多一个分销渠道、多一条触达 GCP 存量客户的路径，代价是每单被抽 1.5-3%
- **谷歌**：云收入 Q2 增 82% 至 248 亿美元、backlog 5140 亿；用自己的 TPU 机群承接竞对模型，按利用率赚两层钱（算力 + 抽成）
- **微软**：4 月失去独家权后只剩「首发权」——议价权降级被包装成关系延续
- **企业买家**：第一次可以在一张云账单上同时买 Gemini 和 GPT，采购与审计都简化

## 三、参照系：Anthropic 的 47%

Anthropic 招股书披露其 2025 年收入的 **47%**（2.16B/4.6B）经云 Marketplace 流入。这组数字说明：Marketplace 抽成不是边缘渠道，而是 AI 模型分发的主干道之一。当模型能力成为「跨云商品」，渠道费率就成了模型厂商新的毛利变量。

## 四、对算力市场的连锁影响

1. **模型与算力解耦加速**：企业选云看数据治理与承诺抵扣，选模型看能力排行——「云锁定模型」的旧逻辑失效
2. **谷歌云的复合优势**：TPU 自研 + Gemini + 第三方模型店面 + 96 万块 Rubin（[A5X 下月 GA](/blog/google-cloud-a5x-rubin-960k-gpu-plans)），成为供给结构最多元的云
3. **英伟达视角**：模型跑在哪朵云上不重要，只要机柜还是它的——GPU 层短期无虞
