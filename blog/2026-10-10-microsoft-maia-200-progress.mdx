# 微软 Maia 200 量产落地：Azure 自研推理芯片的关键一跃

> 距离第一代 Maia 100 发布两年多之后，微软的第二代自研 AI 加速器 Maia 200 终于从传闻走向量产部署。这枚专为推理打造的芯片，正在改写 Azure 的成本结构。

## 从跳票到落地：Maia 200 的问世之路

微软的自研芯片计划于 2023 年 11 月首次公开，与 Cobalt CPU 同期亮相。但 Maia 系列的推进并不顺利，据公开报道，设计变更与人员流失曾迫使时间表一再推迟，量产节点最终落到 2026 年。2026 年 1 月 26 日，微软正式发布 Maia 200，部署几乎随后展开，从首颗封装芯片到机柜上线的时间据称缩短至同类项目的一半以内。

这枚芯片的核心参数相当激进：台积电 3 纳米工艺，单颗集成超过 1400 亿晶体管；配备 216GB HBM3e 显存，带宽达 7TB/s，另有 272MB 片上 SRAM 与专用 DMA 引擎；在 750W 的 SoC 功耗包络内，提供超过 10 PetaFLOPS 的 FP4 算力与超过 5 PetaFLOPS 的 FP8 算力。微软称其 FP4 性能是亚马逊第三代 Trainium 的 3 倍，FP8 性能超过谷歌第七代 TPU，每美元性能较 Azure 现有最新硬件提升 30%。

| 指标 | Maia 200 规格 |
| --- | --- |
| 制造工艺 | 台积电 3 纳米 |
| 晶体管数量 | 超过 1400 亿 |
| 显存 | 216GB HBM3e，7TB/s 带宽 |
| 片上 SRAM | 272MB |
| 算力 | FP4 超过 10 PetaFLOPS，FP8 超过 5 PetaFLOPS |
| 功耗 | 750W SoC TDP |
| 互联 | 每加速器 2.8TB/s 双向 Scale-up 带宽 |
| 集群规模 | 最多 6144 颗加速器 |

## 标准以太网上的超大推理集群

Maia 200 在系统层面有一个鲜明取舍：放弃私有互联协议，全面基于标准以太网构建两层 Scale-up 网络。每颗加速器提供 2.8TB/s 的双向专用带宽，单个托架内四颗芯片通过直连链路全互联，机架内与机架间则统一采用 Maia AI 传输协议，集群规模最大可扩展至 6144 颗加速器。

这套设计的商业逻辑很直白：推理是 Azure 每天承载的最大负载，而以太网生态的成熟度与成本优势远非私有协议可比。配合第二代闭环液冷换热单元和与 Azure 控制平面的原生集成，微软宣称这是其迄今部署过的效率最高的推理系统。

## 服务 GPT-5.2 与 Copilot，但不取代英伟达

Maia 200 首批部署在爱荷华州德梅因附近的 US Central 区域，亚利桑那州菲尼克斯附近的 US West 3 区域紧随其后。它将承载 OpenAI 最新 GPT-5.2 系列模型的推理、Microsoft Foundry 与 Microsoft 365 Copilot 服务；微软超级智能团队也用它进行合成数据生成与强化学习，为下一代自研模型供料。与此同时，微软开放了 Maia SDK 预览，包含 Triton 编译器、PyTorch 支持与模拟器等工具。

值得注意的是，纳德拉明确表示微软将坚持"自研加外购"的双轨策略，继续向英伟达和 AMD 采购芯片。Maia 200 的定位是异构算力矩阵中针对推理优化的一环，而非全面替代。微软 2026 财年第一财季资本开支高达 349 亿美元，自研芯片每一分省下的成本，都直接体现在 Azure AI 的利润率上。

## 小结

从 Maia 100 的试水到 Maia 200 的规模化部署，微软用两年多时间补上了超大规模云厂商自研芯片这块拼图。据公开报道，接替者 Maia 300 已在设计之中，时间线指向 2027 年。在谷歌 TPU 已开始对外销售、亚马逊 Trainium 加速扩张的背景下，Maia 系列的每美元性能优势，将决定 Azure 在 AI 推理时代的议价能力。
