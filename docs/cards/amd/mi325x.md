# AMD Instinct MI325X (CDNA 3 Refresh)

## 产品概述

AMD Instinct MI325X 于 2024 年下半年发布，是 MI300X 的显存升级版本。从 192GB HBM3 升级到 **256GB HBM3e**，带宽从 5.3 TB/s 提升到 **6.48 TB/s**。直接对标 NVIDIA H200。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | CDNA 3 |
| **显存** | **256 GB HBM3e** |
| **显存带宽** | **6.48 TB/s** |
| **FP16 Matrix** | 1,307 TFLOPS（与 MI300X 相同） |
| **FP8 Matrix** | 2,614 TFLOPS |
| **TDP** | 750 W |
| **形式** | OAM |

## MI300X vs MI325X vs H200

| 指标 | MI300X | MI325X | H200 |
|------|--------|--------|------|
| 显存 | 192 GB | **256 GB** | 141 GB |
| 带宽 | 5.3 TB/s | **6.48 TB/s** | 4.8 TB/s |
| 显存类型 | HBM3 | HBM3e | HBM3e |
| FP8 算力 | 2,614 TFLOPS | 2,614 TFLOPS | 3,958 TFLOPS |
