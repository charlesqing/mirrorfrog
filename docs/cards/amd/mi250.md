# AMD Instinct MI250 (CDNA 2)

## 产品概述

AMD Instinct MI250 于 2021 年发布，基于 **CDNA 2 架构**，是 AMD 上一代旗舰加速器。**双芯片 OAM 设计**，128GB HBM2e 显存，FP64 算力 47.9 TFLOPS，是 Frontier 超算（美国首台 E 级超算）的核心组件。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | CDNA 2（GFX90A） |
| **制程** | TSMC 6nm |
| **显存** | **128 GB HBM2e**（双芯片） |
| **显存带宽** | 3,276.8 GB/s |
| **FP32** | 47.9 TFLOPS |
| **FP64** | **47.9 TFLOPS**（矢量） |
| **FP64 Matrix** | 95.2 TFLOPS（峰值） |
| **FP16/BF16 Matrix** | 383 TFLOPS |
| **INT8 Matrix** | 766 TOPS |
| **TDP** | 500 W |
| **互联** | Infinity Fabric 200 GB/s，PCIe 4.0 |
| **形式** | OAM（双芯片） |
| **发布** | 2021-11-08 |

## 关键特性

- **CPU 一致内存架构**（通过 Infinity Fabric）
- **HBM2e 高带宽显存**
- **支持 3D V-Cache 选项**（MI250X）
- 双芯片 OAM 封装

## 适用场景

- HPC 科学计算（FP64 优势）
- AI 训练（PyTorch/TensorFlow with ROCm）
- Frontier 超算（美国首台 E 级）
