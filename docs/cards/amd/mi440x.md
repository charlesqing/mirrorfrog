# AMD Instinct MI440X (CDNA 5, 企业级 8-GPU)

## 产品概述

**AMD Instinct MI440X** 是 **Instinct MI400 系列**的**企业级（Enterprise）SKU**，于 **CES 2026（2026-01-06）** 随 MI400 系列一同披露，定位为标准 **8-GPU 本地服务器**部署（搭配单/双路 **AMD EPYC Venice / Zen 6** CPU），与面向机架级 Helios 平台的旗舰 **MI455X** 形成互补。

截至 2026-08，AMD 尚未发布 MI440X 的官方规格表，也未正式上市；下方参数基于 MI400 系列公开信息与同代 MI455X 平台推算，标注为推测，待官方发布后更新。

## 核心规格

| 项目 | 参数（推测 / 待官方确认） |
|------|------|
| **架构** | CDNA 5 |
| **制程** | TSMC N2（2nm）计算芯粒 + N3（3nm）辅助芯粒（与 MI455X 同源） |
| **显存** | **432 GB HBM4**（沿用 MI400 系列平台） |
| **显存带宽** | 推测 ~19.6–23.3 TB/s |
| **FP4 算力** | 推测 ~40 PFLOPS（MXFP4，同代） |
| **FP8 算力** | 推测 ~20 PFLOPS（MXFP8） |
| **FP64 算力** | 推测 5 TFLOPS（非主权 AI 优化，低于 MI430X 的 288 TFLOPS） |
| **形态** | 标准 8-GPU 服务器（OAM / PCIe，配 EPYC Venice） |
| **互联** | Infinity Fabric（至 EPYC Venice CPU，256 GB/s 双向）+ UALink 横向扩展 |
| **TDP** | 未公开 |
| **首发披露** | **2026-01-06（CES 2026）** |
| **发布状态** | **已披露、未正式发布、无官方规格表** |

> 📌 MI440X 与 MI455X / MI430X 同属 CDNA 5 + 432GB HBM4 平台，差异主要在**部署形态**（8-GPU 服务器 vs Helios 机架 vs HPC/主权 AI）与 **FP64 双精度能力**（MI440X 非 FP64 优化，MI430X 达 288 TFLOPS）。

## MI400 系列内部定位

| SKU | 定位 | 部署形态 | FP64 | 状态 |
|------|------|----------|------|------|
| **MI455X** | 前沿训练 + 推理（旗舰） | Helios 机架（72 卡） | ~5 TFLOPS | 2026-07 发布，H2 出货 |
| **MI440X** | 企业级训练 + 推理 | 标准 8-GPU 服务器 | ~5 TFLOPS | CES 披露，未发布 |
| **MI430X** | HPC / 主权 AI | 超算 / 主权云 | **288 TFLOPS** | 2027 出货 |
| **MI350P** | 企业风冷推理 | 风冷 PCIe（CDNA 4） | — | 已发布 |

## 适用场景

- ✅ **企业本地 AI 训练 / 推理**（标准 8-GPU 服务器，免机架改造）
- ✅ **私有云 / 政企智算**（与 EPYC Venice 协同）
- ❌ 超大规模机架级部署（选 MI455X + Helios）
- ❌ 高精度 HPC / 主权超算（选 MI430X）
