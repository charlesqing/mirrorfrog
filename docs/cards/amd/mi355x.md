# AMD Instinct MI355X (288GB HBM3E)

## 产品概述

**AMD Instinct MI355X** 与 MI350X 同属 **MI350 系列**，均基于 **CDNA 4 架构**、**TSMC 3nm 制程**、**288GB HBM3E** 内存、**8 TB/s 带宽**。**MI350X 与 MI355X 峰值算力基本一致，差异仅在散热与功耗**：MI350X 风冷（TDP 1000W），MI355X 直液冷（TDP 1400W，FP8 dense 5 PFLOPS）。是 **AMD 在 NVIDIA B200/MI400 之间的关键产品**，瞄准 AI 大模型训练与推理市场。

**MI350X 与 MI355X 区别（二者峰值算力相同）**：
- **散热 / 功耗**：MI350X 风冷 TDP 1000W；MI355X 直液冷 TDP 1400W
- **FP8 dense**：MI350X 4.6 PFLOPS；MI355X 5.0 PFLOPS（液冷可维持更高时钟）
- **互联**：均支持 **UALink（原 UALink）600 GB/s**（对标 NVLink 5）

## 8 TB/s 内存带宽技术

| 维度 | 实现方式 |
|------|----------|
| **HBM3E** | 8 个 stack × 1024-bit wide |
| **时钟** | 9.2 Gbps（业界最高） |
| **PHY** | AMD 自研 Infinity Fabric 内存控制器 |
| **预取** | 自适应预取算法 |
| **错误纠正** | On-die ECC + Side-band ECC |

## UALink（Ultra Accelerator Link Fabric）

| 维度 | 规格 |
|------|------|
| **带宽** | **600 GB/s 双向** |
| **拓扑** | 全互联 / Dragonfly+ |
| **协议** | 自研（类 NVLink 但开放） |
| **延迟** | ~1 μs |
| **支持** | MI300X / MI325X / MI350X / MI355X / MI400 全系列 |
| **管理** | UALink Consortium（2024-Q3 成立，AMD / Intel / Meta / Microsoft / Google 等） |
| **2025 成员** | 30+ 公司 |
| **vs NVLink** | 带宽 1/3，但 **完全开放**（NVLink 私有） |

> **UALink 战略意义**：**打破 NVIDIA NVLink 垄断**。B200 1.8 TB/s NVLink 是 UALink 3×，但 UALink 可与 **任何厂商加速器互联**（NVIDIA / Groq / Habana / Tenstorrent），是 **未来 AI 数据中心互联标准**。

## 关键特性

- **288GB HBM3E**：业界最大 HBM 容量，超过 NVIDIA B200 192GB
- **8 TB/s 带宽**：业界最高内存带宽
- **FP4 / FP6 / FP8 多精度**：新代低精度支持（NVIDIA Blackwell 同期）
- **UALink 600 GB/s**：开放互联，对标 NVLink
- **Helios 机柜**：72× MI355X + 36× EPYC Venice + Pensando NIC（2025 H2）
- **开放 ROCm 软件**：vs CUDA 私有
- **缺点**：ROCm 软件成熟度仍落后 CUDA 2-3 年

## 适用场景

- ✅ **大模型训练**（288GB 容纳更大模型，UALink 互联多卡）
- ✅ **LLM 推理**（288GB 装 Llama 3 405B FP16 + 大 KV Cache）
- ✅ **多模态 AI**（Stable Diffusion 3, Sora 训练）
- ✅ **HPC + AI 融合**（ROCm + MPI 兼容）
- ✅ **云服务商**（开放生态，多云部署）
- ✅ **政府/国企**（AMD 美国品牌）
- ❌ CUDA-only 专有工作负载
- ❌ NVLink 紧密耦合代码
