# AMD Instinct MI430X (CDNA 5, HPC / 主权 AI)

## 产品概述

**AMD Instinct MI430X** 是 **Advancing AI 2026（7月）** 发布的 **MI400 系列 HPC / 主权 AI SKU**，面向高精度科学计算与国家级算力项目。与 MI455X 共享 CDNA 5 架构与 **432GB HBM4 / 23.3TB/s** 显存配置，最大差异是**原生硬件级 FP64**：**288 TFLOPS**（NVIDIA Vera Rubin 的 **8.7 倍**）。

MI430X 已锁定两套国家级超算系统：
- 🇺🇸 **美国 ORNL "Discovery"**（橡树岭国家实验室，2028 部署）
- 🇪🇺 **法国 "Alice Recoque"**（GENCI + CEA 联合打造）

AMD 官方在 8/4 财报电话会确认 MI430X 已在 **ORNL 与 Jean Zay（法国）** 的 exascale 超算中运行。**2027 H1 出货**。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | CDNA 5 |
| **制程** | TSMC N2 (2nm) 计算芯粒 + 3nm 辅助芯粒（与 MI455X 相同） |
| **显存** | **432 GB HBM4** |
| **显存带宽** | **23.3 TB/s** |
| **FP64 算力（硬件）** | **288 TFLOPS**（Vera Rubin 的 8.7 倍） |
| **FP32 算力** | ~250 TFLOPS（推测） |
| **MXFP4 算力** | ~40 PFLOPS（推测，同 MI455X） |
| **定位** | **HPC / 主权 AI**（高精度科学计算优先） |
| **TDP** | 推测 1,200-1,500 W |
| **首发** | **2027 H1 出货** |

> 📌 MI430X 是「高精度优先」设计：牺牲部分 AI 吞吐换取 FP64 双精度性能，与 MI455X（AI 吞吐优先）形成互补，同一 Helios 生态。
