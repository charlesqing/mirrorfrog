# NVIDIA T4 (Turing)

## 产品概述

NVIDIA T4 于 2018 年发布，是云端 AI 推理的经典产品，2018-2022 年间大量部署。基于 Turing 架构，**仅 70W TDP** 可被动散热，支持虚拟化（vGPU），是云服务商推理实例的主流 GPU。已被 [NVIDIA L4](/docs/cards/nvidia/l4) 替代。

## 核心规格

| 项目 | 参数 |
| **发布** | 2018 年 9 月 |
|------|------|
| **架构** | Turing TU104 |
| **制程** | TSMC 12nm |
| **显存** | 16 GB GDDR6 |
| **显存带宽** | 320 GB/s |
| **CUDA Core** | 2,560 |
| **Tensor Core** | 320（第二代） |
| **FP32** | 8.1 TFLOPS |
| **INT8 Tensor Core** | 130 TOPS |
| **FP16 Tensor Core** | 65 TFLOPS |
| **TDP** | 70 W |
| **PCIe** | Gen 3 x16 |
| **vGPU** | 支持 |
