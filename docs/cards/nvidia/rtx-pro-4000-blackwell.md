# NVIDIA RTX Pro 4000 Blackwell

## 产品概述

**NVIDIA RTX Pro 4000 Blackwell** 是 NVIDIA 于 2025 年发布的基于 **Blackwell 架构** 的专业工作站显卡，定位 RTX Pro 系列入门级。**24GB GDDR7 ECC 显存**、**145W TDP**（另有 SFF 单插槽 70W 版本），保留第五代 Tensor Core 与 FP4 推理能力，面向轻量 AI 开发与专业图形。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | NVIDIA Blackwell 2.0 (GB202) |
| **制程** | TSMC 4nm |
| **显存** | **24 GB GDDR7 ECC** |
| **显存类型** | GDDR7 |
| **显存带宽** | 未公开（预计 ~600 GB/s） |
| **FP32** | 未公开（预计 ~50 TFLOPS） |
| **FP4 Tensor Core** | 未公开（预计 ~1,000 TFLOPS 推理） |
| **TDP** | 145 W（SFF 版 70W） |
| **PCIe** | Gen 5 x16 |
| **ECC** | 支持 |
| **MIG** | 支持 |
| **发布时间** | 2025 年 |

## 版本差异

| 版本 | TDP | 形态 |
|------|-----|------|
| **工作站版** | 145W | 双插槽主动散热 |
| **SFF 版** | 70W | 单插槽小尺寸 |

## 关键特性

- **24GB GDDR7 ECC 显存**：支持本地 14B-30B 模型推理
- **第五代 Tensor Core**：支持 FP4 推理
- **专业驱动 + ECC**：工作站稳定之选
- **145W 低功耗**：SFF 版 70W 适配小机箱
