# NVIDIA B200 (Blackwell)

## 产品概述

NVIDIA B200 是 Blackwell 架构的旗舰 GPU，**单卡 FP4 算力 20 PFLOPS**（稀疏），是当前（2025）性能最强的 AI 训练和推理 GPU。B200 与 B100 同样使用双芯片设计，但 TDP 提升到 **1,000 W**，需要重新设计的服务器和液冷方案。NVIDIA 还推出了 **GB200 Grace Blackwell Superchip**（2× B200 + Grace CPU）和 **NVL72** 整机柜（72 颗 B200 + 36 颗 Grace）。

## 核心规格

| 项目 | 参数 |
|------|------|
| **发布** | 2024 年 GTC，2025 年大规模量产 |
| **架构** | Blackwell GB100（双 die） |
| **制程** | TSMC 4NP |
| **晶体管数** | **2,080 亿** |
| **显存** | 192 GB HBM3e |
| **显存带宽** | 8 TB/s |
| **FP4 Tensor Core** | **20 PFLOPS**（稀疏；密集 10 PFLOPS） |
| **FP8 Tensor Core** | **10 PFLOPS**（稀疏；密集 5 PFLOPS） |
| **FP16 Tensor Core** | 5 PFLOPS（稀疏；密集 2.5 PFLOPS） |
| **FP64** | 40 TFLOPS |
| **NVLink** | 1.8 TB/s（第五代） |
| **TDP** | 1000 W |
| **PCIe** | Gen 5 |

> **算力口径**：上表 Tensor Core 数值均为**稀疏（sparse）**，密集值见括号。NVIDIA 官方同时公布两套数字，跨厂商对比时务必统一口径。
> **显存口径**：192 GB 为官方标称最大容量；HGX B200 实际出货配置为 180 GB HBM3e（7.7 TB/s），GB200 Superchip 为 372 GB / 16 TB/s（每GPU 186 GB）。

## 软件与驱动

- **驱动**：https://www.nvidia.com/Download/index.aspx
- **CUDA**：12.5+ 推荐
- **TensorRT-LLM**：B200 原生 FP4 推理支持
- 与 H100 同一软件栈，几乎无缝迁移

## 关键特性

- **第二代 Transformer Engine**：FP4 / FP6 自动精度切换
- **Mixture of Experts (MoE) 优化**：硬件加速 MoE 模型路由
- **Confidential Computing**：硬件级加密计算
- **RAS Engine**：服务器级可靠性

## 适用场景

- **万亿参数 LLM 训练**
- 大规模 AI 推理（万亿参数单卡推理）
- MoE 模型（Mixtral、Llama 4 等）
- 多模态大模型
- 科学计算（HPC）
