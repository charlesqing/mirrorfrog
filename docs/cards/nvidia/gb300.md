# NVIDIA GB300 (Grace Blackwell 300)

## 产品概述

**NVIDIA GB300 (Grace Blackwell 300)** 是 NVIDIA 第三代 **Grace Blackwell超级芯片**（Superchip），**2026 H1 规模出货**。将 **2× B300 Ultra GPU**（升级版 Blackwell）通过 **NV-HBI 高速接口**与 **Arm Grace CPU** 配对，**单 Superchip = 2× B300 Ultra GPU + 1 Grace CPU**。36 颗 GB300 组成 **NVL72 机柜（共 72 颗 B300 Ultra + 36 颗 Grace）**，**NVLink 5 + ConnectX-8 800G 网络** 互联，是 **NVIDIA 数据中心 AI 的旗舰机柜级产品**。

**代际演进**：
- **GH200**（2023-Q3）：Grace Hopper，H100 + 72-core Arm Grace
- **GB200**（2024-Q4）：Grace Blackwell，2× B200 + 72-core Arm Grace
- **GB300**（2025 GTC 首发，2026 H1 出货）：2× B300 Ultra + **Arm Grace 72 核** CPU + **ConnectX-8 800G**

| **FP4 稀疏** | **40 PFLOPS**（单 Superchip，2 GPU） |

| **FP8 稀疏** | **20 PFLOPS**（单 Superchip） |
| **FP8 密集** | **10 PFLOPS**（单 Superchip） |
| **FP16/BF16 稀疏** | **10 PFLOPS**（单 Superchip） |

> **算力口径**：单 GPU 为 Blackwell Ultra（NVFP4 密集 15 / 稀疏 20 PFLOPS），单 Superchip 为 2× GPU。上表均为单 Superchip 口径。NVIDIA 官方 GB300 NVL72 机柜级合计为 FP4 1,440 PFLOPS（稀疏）/ 1,080 PFLOPS（密集）。
> **TDP 口径**：3,000 W 为单 Superchip（2× B300 Ultra + Grace）估算值；NVIDIA 官方仅公布单 GPU 最高 1,400 W，DGX Station 桌面版 Superchip 功耗上限约 1,300 W。机柜级功耗约 132–154 kW。

| CPU 数 | 36 Grace | 288 Grace |

## 关键特性

- **NVL576 域**：8 机柜 576 GPU 共享 130 TB/s 互联（业界最大）
- **ConnectX-8 800G**：每 GPU 800 Gb/s 跨机柜网络
- **FP4 20 PFLOPS 稀疏/ 15 PFLOPS 密集**：单 GPU 算力，对推理优化
- **统一内存**：GPU 576GB HBM3E + CPU 480GB LPDDR5X 一致性寻址
- **缺点**：单Superchip 功耗约 3,000 W，必须全液冷

## NVL72 适用场景

- ✅ **万亿参数 LLM 训练**（576 GPU 域，130 TB/s NVLink）
- ✅ **MoE 模型训练**（专家并行 + 张量并行混合）
- ✅ **超大规模 RLHF**（576 GPU 同步）
- ✅ **多模态大模型**（视频 + 文本 + 图像）
- ✅ **AI for Science**（气候、材料、生命科学）
- ❌ 小规模推理（成本过高）
- ❌ 中国市场（出口管制）
