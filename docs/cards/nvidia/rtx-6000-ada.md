# NVIDIA RTX 6000 Ada Generation

## 产品概述

NVIDIA RTX 6000 Ada 是面向专业工作站的高端 GPU，2022 年发布。基于 **Ada Lovelace AD102** 完整核心，**48GB GDDR6 ECC 显存**（双倍于 RTX 4090），FP8 算力 **1,458 TFLOPS**。ECC 显存对长时间 AI 训练至关重要。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | Ada Lovelace AD102 |
| **制程** | TSMC 4N |
| **显存** | **48 GB GDDR6 ECC** |
| **显存带宽** | 960 GB/s |
| **CUDA Core** | 18,176 |
| **Tensor Core** | 568（第四代） |
| **FP32** | 91.1 TFLOPS |
| **FP8 Tensor Core** | 1,458 TFLOPS（稀疏） |
| **INT8 Tensor Core** | 2,916 TOPS |
| **TDP** | 300 W |
| **PCIe** | Gen 4 x16 |
| **ECC** | 支持 |

## 适用场景

- **AI 开发工作站**（模型训练、微调、推理）
- **大模型本地推理**（70B+ 可用）
- **专业图形**（CAD、3D 渲染）
- **数据科学**（带 ECC 显存）

## 关键差异 vs RTX 4090

- 显存：48GB（2× 于 RTX 4090）
- ECC 显存支持
- 专业驱动（NVIDIA RTX Enterprise）
- vGPU 支持
- 单槽宽 / 双槽设计（vs RTX 4090 三槽）
