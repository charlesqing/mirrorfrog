# NVIDIA L40S (Ada Lovelace)

## 产品概述

NVIDIA L40S 于 2023 年发布，是面向数据中心的**多用途 GPU**，横跨 AI 推理、3D 渲染（Omniverse）、视频转码和科学计算。基于 **Ada Lovelace AD102** 完整核心，48GB GDDR6 ECC 显存，**733 TFLOPS FP8** 算力，350W TDP。L40S 是 L40 的替代品，也常被用于虚拟化（vGPU）。

## 核心规格

| 项目 | 参数 |
| **发布** | 2023 年 8 月 |
|------|------|
| **架构** | Ada Lovelace AD102 |
| **制程** | TSMC 4N |
| **显存** | 48 GB GDDR6 ECC |
| **显存带宽** | 864 GB/s |
| **CUDA Core** | 18,176 |
| **Tensor Core** | 568（第四代） |
| **FP32** | 91.6 TFLOPS |
| **FP8 Tensor Core** | 733 TFLOPS（稀疏） |
| **INT8 Tensor Core** | 1,466 TOPS |
| **TDP** | 350 W |
| **PCIe** | Gen 4 x16 |
| **视频编解码** | 3× NVENC（AV1）+ 3× NVDEC（AV1） |
| **vGPU** | 支持 |
