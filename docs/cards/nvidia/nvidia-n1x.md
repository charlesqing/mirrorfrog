# NVIDIA N1X（PC 处理器）

## 产品概述

**NVIDIA N1X** 是 NVIDIA **首款以自有品牌进军 PC 处理器市场**的芯片，标志 NVIDIA 正式向长期由 Intel 与 AMD 主导的 x86 PC 处理器市场发起正面挑战。该芯片由 NVIDIA 与 **微软合作**打造，基于 **RTX Spark 平台**衍生，面向消费级和 OEM Windows PC 市场，计划 **2026 年秋季**上市。

2026 年 10 月 4 日 N1X 正式公布后，市场反应剧烈：**Intel 与 AMD 股价当日各下跌约 4.2%**——投资者认为 NVIDIA 凭借其在 AI 与游戏硬件领域建立的制造关系、芯片设计能力与品牌号召力，对传统 PC 处理器双寡头构成的威胁是结构性的，而非边缘性尝试。

N1X 的底层能力继承自 RTX Spark：**Arm CPU + Blackwell GPU 统一内存架构**，定位「智能体 AI（Agentic AI）」PC 平台——让大模型和 AI Agent 在本地 Windows 设备上原生运行。这与高通 Snapdragon X Elite 借 Arm 架构切入 Windows PC 的路线形成直接竞争，但 NVIDIA 的差异化在于其 GPU 生态（CUDA、DLSS、RTX 游戏/创作栈）的完整度。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | Arm CPU + Blackwell GPU（RTX Spark 衍生） |
| **合作方** | 微软（平台与 Windows 集成）、联发科（CPU 架构，业内推测） |
| **市场定位** | 消费级 / OEM Windows PC（笔记本 + 桌面） |
| **统一内存** | 与 RTX Spark 同源（LPDDR5X 统一内存架构） |
| **TDP** | 未公开 |
| **上市** | **2026 年秋季** |
| **发布** | 2026-10-04（正式公布） |

> ⚠️ **规格说明**：NVIDIA 尚未公布 N1X 的核心数、算力、内存容量与定价等详细规格。上表仅列出已确认信息，其余细节预计随 2026 年秋季上市临近逐步披露。

## 市场意义

| 维度 | 影响 |
|------|------|
| **对 Intel / AMD** | PC 处理器市场首次出现第三强玩家，发布当日两家股价各跌约 4.2% |
| **对高通** | Arm Windows PC 市场从「高通独占」转为多头竞争 |
| **对苹果** | Apple Silicon 的「统一内存 + 自研架构」路线获得最强劲的 Windows 阵营对标 |
| **对 OEM** | Dell、HP、Lenovo、Asus、MSI、Microsoft Surface 等获得新的芯片供应选项 |

## 关键看点

1. **AI PC 竞争升维**：N1X 不打传统性能战，而是把「本地跑大模型 / Agent」作为核心卖点，这与 RTX Spark「1,200 亿参数模型 + 100 万 token 上下文」的平台叙事一脉相承
2. **x86 护城河受考验**：Windows 应用兼容性、OEM 采纳意愿和实际性价比，是 N1X 能否转化市场份额的关键
3. **后续信号**：独立基准测试成绩与主要 OEM 的定点机型公告，是判断 N1X 实际竞争力的最直接依据
