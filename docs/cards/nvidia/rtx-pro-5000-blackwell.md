# NVIDIA RTX Pro 5000 Blackwell

## 产品概述

**NVIDIA RTX Pro 5000 Blackwell** 是 NVIDIA 于 2025 年发布的基于 **Blackwell 架构** 的专业工作站显卡，是 RTX Pro 6000 Blackwell 的精简版。**48GB GDDR7 ECC 显存**（另有 72GB 版本）、**300W TDP**，保留第五代 Tensor Core 与 FP4 推理能力，是 **本地大模型开发、专业图形** 的高性价比工作站卡。

**战略地位**：在 RTX Pro 6000（96GB）与消费级 RTX 5090（32GB）之间，RTX Pro 5000 以 **48GB ECC 显存 + 专业驱动** 填补了中端 AI 工作站空白，兼顾显存容量与成本。

## 关键特性

- **48GB GDDR7 ECC 显存**：支持本地 70B 级模型推理
- **第五代 Tensor Core**：支持 FP4 推理
- **专业驱动 + ECC**：企业 AI 工作站稳定之选
- **PCIe 5.0**：带宽升级
