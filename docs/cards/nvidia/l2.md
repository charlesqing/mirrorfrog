# NVIDIA L2 (Ada 入门级推理)

## 产品概述

**NVIDIA L2** 是 Ada Lovelace 架构、**面向中国市场推出的出口合规特供推理卡**（与 H20、L20 同属合规产品线），定位低于 L4。24GB GDDR6 ECC 显存，**单槽 / 半高半长（LP）**形态，专为空间与功耗敏感的部署设计。

主要面向**边缘服务器、电信运营商、零售业**等低功耗 AI 推理场景。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | Ada Lovelace（AD104 精简） |
| **制程** | TSMC 4N |
| **CUDA 核心** | 4,608 |
| **Tensor 核心** | 144（第四代） |
| **RT 核心** | 36（第三代） |
| **显存** | 24 GB GDDR6 ECC |
| **显存带宽** | 300 GB/s |
| **FP8 Tensor** | 193 TFLOPS（密集）/ 386 TFLOPS 稀疏 |
| **FP16/BF16 Tensor** | 96.5 TFLOPS |
| **INT8 Tensor** | 193 TOPS（密集）/ 386 TOPS 稀疏 |
| **TF32 Tensor** | 48.3 TFLOPS |
| **FP32** | 24.1 TFLOPS |
| **TDP** | 未公布 |
| **形态** | PCIe Gen4 ×16 单槽 / 半高半长（LP） |
| **首发** | 2024 上半年（中国市场） |
| **价格** | 未公布 |

## L2 vs L4 vs T4 对比

| 指标 | L2 | L4 | T4 |
|------|-----|-----|-----|
| 架构 | Ada | Ada | Turing |
| CUDA 核心 | 4,608 | 7,680 | 2,560 |
| 显存 | 24GB GDDR6 | 24GB GDDR6 | 16GB GDDR6 |
| 带宽 | 300 GB/s | 300 GB/s | 320 GB/s |
| FP8 Tensor（稀疏） | 386 TFLOPS | 485 TFLOPS | N/A |
| TDP | 未公布 | 72W | 70W |
| 形态 | 单槽 LP | 单槽 | 单槽 |

> L2 FP8 稀疏算力约为 L4 的 80%，两者带宽相同；L2 的差异化在更低价与半高低功耗形态。

## 适用场景

- ✅ **边缘服务器 AI 推理**（5G MEC）
- ✅ 电信运营商 vRAN + AI 联合
- ✅ 零售业边缘 AI（视频分析）
- ✅ 嵌入式数据中心
- ❌ 大模型推理（应使用 L40S/H100）
- ❌ 训练（无 NVLink，多卡扩展效率低）
