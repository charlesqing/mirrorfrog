# NVIDIA RTX Pro 4500 Blackwell

## 产品概述

**NVIDIA RTX Pro 4500 Blackwell** 是 NVIDIA 于 2025 年发布的基于 **Blackwell 架构** 的专业工作站显卡，定位 RTX Pro 系列中端。**32GB GDDR7 ECC 显存**、**200W TDP**，保留第五代 Tensor Core 与 FP4 推理能力，面向主流 AI 开发与专业图形工作负载。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | NVIDIA Blackwell 2.0 (GB202) |
| **制程** | TSMC 4nm |
| **显存** | **32 GB GDDR7 ECC** |
| **显存类型** | GDDR7 |
| **显存带宽** | 未公开（预计 ~900 GB/s） |
| **FP32** | 未公开（预计 ~70 TFLOPS） |
| **FP4 Tensor Core** | 未公开（预计 ~1,500 TFLOPS 推理） |
| **TDP** | 200 W |
| **PCIe** | Gen 5 x16 |
| **ECC** | 支持 |
| **MIG** | 支持 |
| **发布时间** | 2025 年 |

## 关键特性

- **32GB GDDR7 ECC 显存**：支持本地 30B-70B 模型推理
- **第五代 Tensor Core**：支持 FP4 推理
- **专业驱动 + ECC**：工作站稳定之选
- **200W 低功耗**：风冷友好
