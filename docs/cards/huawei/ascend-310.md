# Huawei Ascend 310

## 产品概述

**Huawei Ascend 310**（昇腾 310）是华为昇腾系列**首款 AI 芯片**，于 **2018 年 10 月**在第五届世界互联网大会发布，与 Ascend 910 共同开启华为"达芬奇（Da Vinci）架构"全场景算力体系。

Ascend 310 定位**边缘计算与端侧推理**，最大亮点为 **8W 极致低功耗**，开创了华为"一套架构覆盖毫瓦级到数百瓦级"的统一思路。它是智能摄像头、边缘服务器、终端 AI 推理的核心算力来源，也是华为智能驾驶芯片（昇腾 610 系列）的技术起点。

## 核心规格

| 项目 | 参数 |
|------|------|
| **发布** | 2018-10（世界互联网大会） |
| **架构** | Da Vinci（达芬奇，初代） |
| **制程** | 12nm（台积电） |
| **AI Core** | 2 颗达芬奇 AI Core（部分资料 8 核） |
| **CPU** | 集成 ARM Cortex-A55 等控制核 |
| **FP16** | **8 TFLOPS** |
| **INT8** | **16 TOPS** |
| **显存** | LPDDR4x |
| **TDP** | **8 W**（极致低功耗） |
| **视频解码** | 16 通道全高清 H.264/H.265 |
| **典型场景** | 智能摄像头、边缘服务器、终端 AI |

## 关键特性

- **8W 超低功耗**：达芬奇架构能效比标杆，适配电池供电与无风扇设备
- **全场景架构起点**：同一达芬奇架构从端侧到云端灵活裁剪
- **视频编解码**：集成 16 通道全高清硬件解码
- **规模化落地**：支撑 Atlas 200 / 500 / 300 等数十款边缘硬件
