# 华为 Ascend 310P

## 产品概述

**华为 Ascend 310P** 是华为海思基于 **达芬奇（DaVinci）架构** 打造的面向 **边缘计算与端侧推理** 的低功耗 AI 处理器，为 Ascend 310 的升级版。集成 10 个达芬奇 AI Core、泰山 CPU 核心与视频编解码单元，**INT8 峰值算力 140-176 TOPS**，**FP16 约 70 TFLOPS**，典型芯片功耗仅 **8W**（整卡如 Atlas 300I Pro 约 70W）。

**战略地位**：310P 是华为边缘 AI 的主力芯片，广泛部署于 Atlas 300I 系列推理卡、AI 计算盒子（如 OrangePi AI Station，本地运行 Llama-2-7B），是国产化边缘推理的首选。

|------|------|

| **FP16 算力** | 70 TFLOPS |

| **显存** | LPDDR4X（24GB / 48GB / 96GB，依板卡） |

| **显存带宽** | 204.8 GB/s |
| **视频解码** | 128 路 1080P@30fps |
| **TDP** | 70 W（整卡；芯片约 8W） |
| **发布时间** | 2022 年 |
| **价格** | 约 ¥1.5 万（Atlas 300I Pro 整卡） |

## 关键特性

- **低功耗高能效**：典型 8W 芯片功耗，适合电池供电设备
- **大内存带宽**：384-bit LPDDR4X，理论 204.8 GB/s
- **视频编解码**：支持 128 路 1080P 硬件解码
- **CANN 生态**：兼容 PyTorch / TensorFlow，AscendCL 开发
