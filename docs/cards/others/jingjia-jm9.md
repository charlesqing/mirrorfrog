# 景嘉微 JM9 系列

## 产品概述

**长沙景嘉微电子（Jingjia Micro，深交所 300474）** 成立于 2006 年，是中国**首家成功研制国产 GPU 芯片并实现大规模工程应用**的企业。公司起家于军用图形显控领域，先后推出 **JM5400**（2014，65nm，用于国产军机替代 AMD/ATI 方案）、**JM7200**（2018，28nm，性能约等于 NVIDIA GT 640 但功耗不足 10W）两代 GPU，随后进入民用信创市场。

**JM9 系列** 是景嘉微**第三代 GPU**，属公司 2018 年非公开发行募投项目「高性能通用图形处理器研发及产业化项目」的核心成果。**2021-11-16**，景嘉微发布正式公告称 JM9 系列图形处理芯片已**完成流片、封装及初步测试**，主要技术指标符合设计要求。**2022-05**，JM9 系列**第二款**图形处理芯片研发成功，侧重台式机、服务器、工控机、自助终端等设备。

JM9 系列对外公开的型号命名为 **JM9231** 与 **JM9271**：前者定位国产化办公电脑、便携式计算机、中低端娱乐设备与高端嵌入式系统；后者强化科学计算能力，面向人工智能、安防监控、语音识别、云计算等方向。整个系列大量应用于各地**信创国产化办公替换项目**，以及专业测绘、地质信息处理、工业辅助设计等场景。

截至 **2026-03**，景嘉微在投资者互动平台确认 **JM9 系列已实现批量交付**；同时公司第四代 GPU **JM11 系列**已上市并进入小批量出货阶段，JM9 转为在役主力产品之一。

> ⚠️ **重要说明：两套流传规格并存**
> 网络与研报中广泛流传的 JM9231/JM9271「2 TFLOPS / 8 TFLOPS FP32、256/512 GB/s、150W/200W、对标 GTX 1050 / GTX 1080」一表，最早源自 **2019 年媒体报道（MyDrivers、Tom's Hardware）与券商研报**，**并非景嘉微官方发布的规格**。景嘉微相关负责人曾公开表示，JM9 系列与 GTX 1080「在市场地位、应用特点、侧重点等方面均有不同，不具备可比条件」。
> 本页「核心规格」表**以 2021-11-16 景嘉微深交所正式公告披露的官方指标为准**，传闻规格另列于下方对照表并明确标注。

## 核心规格

以下为 **2021-11-16 景嘉微官方公告** 披露的 JM9 系列图形处理芯片（首款）实测指标。

| 项目 | 参数 |
|------|------|
| **架构** | JM9 自研 GPU 架构（统一渲染架构） |
| **制程** | 未公开（媒体报道称 14nm，官方未确认） |
| **FP16 / BF16 算力** | 未公开 |
| **INT8 算力** | 未公开 |
| **FP32 算力** | **1.5 TFLOPS**（32 位单精度浮点，官方公告） |
| **像素填充率** | 32 GPixels/s |
| **核心频率** | 1.5 GHz（支持动态调频） |
| **显存容量** | 8 GB |
| **显存类型** | 未公开（官方公告未标注类型） |

| **视频解码** | 4 路 4K@60fps（H.265 / H.264 / MPEG2 / MPEG4 硬解） |

| **发布** | 2021-11（流片封装及初步测试完成公告） |

## 关键特性

- **全自主 GPU 架构**：掌握芯片底层逻辑/物理设计、模拟接口设计、GPU 驱动程序设计等全链条关键技术，非 IP 授权改版
- **信创全栈适配**：官方明确支持 x86 / ARM / MIPS 处理器，以及中标麒麟、银河麒麟、统信 UOS 等国产操作系统
- **极低功耗**：官方指标 < 30W，可支持无风扇/低散热设计，适合政务办公终端与嵌入式设备
- **多屏输出能力强**：4 路独立图形显示控制器，支持 4×HDMI 2.0 + 2×eDP + 1×VGA
- **完整视频编解码**：4 路 4K@60 硬解 + 1 路 4K@60 硬编
- **军工级可靠性积累**：延续 JM5400/JM7200 在航空航天严苛环境下的高可靠设计经验
- **GIS/CAD 场景优势**：与超图软件等国产工业软件深度适配，形成「CPU+GPU+OS+GIS」自主可控闭环
- **局限**：AI 算力（FP16/INT8）从未官方披露，不适合作为 AI 训练或大模型推理卡；单卡无互联能力

## 适用场景

- ✅ 信创国产化办公电脑 / 便携式计算机显卡替换
- ✅ 政务、金融、交通、通信等行业桌面终端国产化
- ✅ 地理信息系统（GIS）、3D 实景地图渲染
- ✅ CAD 辅助设计、工业制图、工业数字孪生
- ✅ 高端嵌入式系统、工控机、自助终端
- ✅ 多媒体处理与 4K 视频编解码
- ✅ 军用/特种显控设备（公司传统优势领域）
- ❌ AI 大模型训练（无公开 FP16/BF16 算力，无高速互联）
- ❌ 大模型推理集群（显存 8GB、带宽 128 GB/s 不足）
- ❌ 高端 3A 游戏（图形 API 支持等级与生态受限）
- ❌ CUDA 生态工作负载（需重新移植）
