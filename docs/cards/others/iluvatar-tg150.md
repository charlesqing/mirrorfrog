# 天数智芯 天垓150 (BI-V150)

## 产品概述

**天垓150**（型号 **BI-V150**）是天数智芯于 **2023 年**发布的第二代云端**通用 GPU 训练加速卡**，为天垓100（BI-V100）的升级版本。采用通用 GPU 架构，兼容国际主流 GPU 通用计算模型，支持国内外主流 AI 生态和深度学习框架及原生算子，在性能上相较前代有显著提升。

**关键特性**：作为新一代产品，天垓150 在 FP16 算力和显存带宽上均有提升，能够胜任大规模 AI 训练和复杂计算需求。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | 天数智芯自研通用 GPU 架构（天垓100升级版） |
| **制程** | **7nm**（推测，与天垓100相同） |
| **FP16** | 未公开（推测 150–200 TFLOPS） |
| **INT8** | 未公开（推测 300–400 TOPS） |
| **显存容量** | 推测 32–64 GB HBM2/HBM3 |
| **显存带宽** | 未公开 |
| **TDP** | 275 W（推测） |
| **接口** | PCIe Gen4（推测） |
| **发布** | **2023 年** |
| **量产** | 2023 年起 |
| **软件栈** | 天数智算软件栈（兼容 PyTorch/TensorFlow） |

> ⚠️ **规格说明**：天垓150 的详细规格官方未完整公开，以上部分为推测值，以天数智芯后续官方数据表为准。

## 天垓100 vs 天垓150

| 指标 | 天垓100（BI-V100）| **天垓150（BI-V150）** | 提升 |
|------|-------------------|-------------------------|------|
| 发布 | 2021 年 | **2023 年** | 新一代 |
| FP16 | 128 TFLOPS | **推测 150–200 TFLOPS** | +20–55% |
| INT8 | 256 TOPS | **推测 300–400 TOPS** | +20–55% |
| 软件生态 | 初代 | **更成熟** | 迭代优化 |

## 混合训练案例

天垓150 已参与实际大规模训练部署：

- **智源研究院 Aquila2-70B-Expr 大模型混合训练**：利用 **120 节点 BI-V100 集群** + **8 节点 BI-V150 集群**进行混合训练，混合集群性能达到理论上界（理想合池理论峰值）的 **85.3%**，展现了出色的异构算力混合训练能力。

## 适用场景

- ✅ **大规模 AI 训练**（千亿参数以下模型）
- ✅ **异构算力集群**（与天垓100混合部署）
- ✅ **科学计算**（FP32/INT32 支持）
- ✅ **智慧城市**（交通流量分析、环境监测）
- ✅ **数据中心**（云计算、大数据加速）
- ❌ **超高算力需求**（FP16 仍低于 H100/A100）
- ❌ **新兴 FP8 精度**（不支持 FP8）
