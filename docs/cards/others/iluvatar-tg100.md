# 天数智芯 天垓100 (BI-V100)

## 产品概述

**天垓100**（型号 **BI-V100**）是天数智芯于 **2021 年 3 月**正式发布的**国产首款全自研通用 GPU 训练加速卡**，采用 **7nm 工艺**，配备 **32GB HBM2 显存**，板级功耗 **250W**，支持 FP32/FP16/INT8 混合精度训练，兼容国际主流 GPU 通用计算模型，支持 PyTorch/TensorFlow 等主流 AI 框架，是天数智芯"天垓"训练产品系列的开山之作。

**战略意义**：实现了国产通用 GPU 产品从 0 到 1 的重大突破，填补了国产云端训练 GPU 的空白。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | 天数智芯自研通用 GPU 架构 |
| **制程** | **7nm**（推测 TSMC） |
| **FP16** | **128 TFLOPS** |
| **INT8** | **256 TOPS** |
| **INT32** | **32 TFLOPS** |
| **显存容量** | **32 GB HBM2** |
| **显存带宽** | 未公开（推测 ~1 TB/s） |
| **TDP** | **250 W**（板级功耗） |
| **接口** | **PCIe Gen4.0 x16** |
| **片间互联** | 64 GB/s 双向带宽 |
| **散热** | 被动散热 |
| **尺寸** | 全长全高双槽 PCIe 卡 |
| **发布** | **2021 年 3 月** |
| **量产** | 2021 年起 |
| **软件栈** | 天数智算软件栈（兼容 PyTorch/TensorFlow） |

> ⚠️ **规格说明**：显存带宽官方未完整公开，以天数智芯后续官方数据表为准。

| 层级 | 工具 | 说明 |

## 适用场景

- ✅ **国产大模型训练**（千亿参数以下）
- ✅ **AI 框架迁移**（兼容 CUDA 编程模型）
- ✅ **政府/国企 AI 项目**（供应链安全）
- ✅ **科学计算**（FP32/INT32 支持）
- ❌ **超高算力需求**（FP16 128 TFLOPS 低于 H100）
- ❌ **新兴 FP8 精度**（不支持 FP8）

## 与智铠100（MR100）对比

| 指标 | 天垓100（BI-V100）| 智铠100（MR100）| 差异 |
|------|-------------------|-------------------|------|
| 定位 | 训练（Training）| 推理（Inference）| 场景不同 |
| FP16 | 128 TFLOPS | 96 TFLOPS | 天垓更强 |
| INT8 | 256 TOPS | 192 TOPS | 天垓更强 |
| 视频解码 | 不支持 | 128 路 1080P | 智铠独有 |
| TDP | 250W | 推测 250–300W | 相近 |
