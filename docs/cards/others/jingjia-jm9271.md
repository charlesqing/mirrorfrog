# 景嘉微 JM9271

## 产品概述

**JM9271** 是 **长沙景嘉微电子（深交所 300474）** JM9 系列中定位更高的型号。按公司在 2018 年非公开发行募投项目中的规划，JM9 系列包含 **JM9231** 与 **JM9271** 两款芯片：JM9231 面向国产化办公电脑、便携式计算机、中低端娱乐设备与高端嵌入式系统；**JM9271 则重点强化科学计算与数据运算能力**，面向人工智能、安防监控、语音识别、深度学习、云计算等对计算速度要求较高的高端应用领域。

**2021-11-16**，景嘉微公告 JM9 系列图形处理芯片已完成流片、封装与初步测试。**2022-05**，公司宣布 JM9 系列**第二款**图形处理芯片研发成功，该型号侧重台式机、服务器、工控机、自助终端等设备应用——业界普遍将这款「第二款芯片」对应到 JM9271，但**景嘉微在公告中并未使用 JM9271 型号名，也未单独披露该型号的完整技术指标**。

在实际市场落地方面，2026 年的行业盘点文章将 JM9271 描述为景嘉微 JM9 系列的**代表产品**，称其采用自研 JM9 图形架构，支持 Vulkan / OpenGL 等图形 API 与 4K 超高清显示输出，图形渲染能力处于国内第一梯队，并与麒麟信安联合推出全国产 GPU 虚拟化解决方案，在电网调度等关键基础设施中部署。截至 **2026-03**，景嘉微确认 **JM9 系列已实现批量交付**，第四代 **JM11 系列**已上市并小批量出货，公司同时仍在推进「高性能通用 GPU 芯片」与下一代图形处理芯片研发。

> ⚠️ **本页规格性质说明（务必阅读）**
> 景嘉微**从未以官方公告形式单独发布 JM9271 的完整规格表**。下方核心规格中标注「传闻」的字段，来源为 **2019—2021 年媒体报道（MyDrivers / Tom's Hardware）与券商研报**，属早期设计目标或二手转述，且不同来源之间存在互相矛盾之处（见「来源冲突」小节）。
> 景嘉微相关负责人曾公开回应，JM9 系列与 GTX 1080「在市场地位、应用特点、侧重点等方面均有不同，不具备可比条件」，因此**「对标 GTX 1080」应视为媒体口径而非官方定位**。

### 来源冲突

| 指标 | 来源 A（2019—2021 媒体/研报） | 来源 B（2026-08 行业盘点） |
|------|------------------------------|---------------------------|
| 显存容量 | 16 GB | 8 GB |
| 显存类型 | HBM | GDDR6 |
| 显存带宽 | 512 GB/s | 512 GB/s（另一篇同期文章） |
| FP32 | 8 TFLOPS | 8 TFLOPS |

> ⚠️ **不确定性**：显存配置存在 **16GB HBM** 与 **8GB GDDR6** 两种互相矛盾的流传说法。HBM 方案在 2019 年被多家英文媒体报道，但 HBM 成本高昂、供应受限，实际量产版本改用 GDDR6 亦属合理推测。**在缺乏官方规格书的情况下，两种说法均无法证实。**

## 关键特性

- **JM9 系列高端定位**：相较 JM9231，强化数据运算与批量信息处理能力，可承担基础数据分析、地理信息运算等负载
- **自研 JM9 图形架构**：非 IP 授权改版，景嘉微掌握底层逻辑/物理设计与驱动栈
- **GPU 硬件虚拟化**：与麒麟信安联合推出全国产 GPU 虚拟化方案，已在电网调度等关键基础设施落地
- **4K 超高清输出**：支持 4K 显示输出与 H.265 硬件编解码
- **国内第一梯队图形渲染**（2026 年行业盘点口径）
- **军工级可靠性**：延续公司在航空航天严苛环境下的高可靠设计积累
- **专业行业落地**：专业测绘、地质信息处理、工业辅助设计、指挥调度
- **局限**：AI 算力（FP16/BF16/INT8）从未披露，无法用于大模型训练；无公开高速互联；官方规格长期不透明
