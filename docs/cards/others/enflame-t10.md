# 燧原科技 云燧 T10

> 燧原科技首款人工智能训练加速卡，基于自研邃思1.0芯片，2019年12月发布，中国最早量产的高性能AI训练卡之一。

---

## 核心规格

| 规格 | 参数 |
|------|------|
| **架构** | 邃思1.0（DTU 数据流架构） |
| **制程** | 格芯 12nm FinFET |
| **晶体管数** | 141 亿 |
| **TDP** | 225 W |
| **显存** | 32 GB HBM2 |
| **显存带宽** | 512 GB/s |
| **FP32 算力** | 20 TFLOPS |
| **FP16 / BF16 算力** | 80 TFLOPS |
| **INT8 算力** | 160 TOPS（预估） |
| **接口** | PCIe 4.0 x16，双槽 |
| **互联** | 燧原 ESL 200GB/s（双向） |
| **首发** | 2019-12-11 |
| **价格** | 未公开（预估 ¥40,000） |

---

## 技术亮点

- **邃思1.0 芯片**：燧原科技自研首代云端AI训练芯片，采用格芯12nm工艺，2.5D先进封装，集成141亿晶体管
- **DTU 数据流架构**：专为AI训练设计的可重构数据流架构，支持动态任务调度
- **ESL 高速互联**：自研200GB/s双向互联技术，支持1024节点集群训练，线性加速比达86%
- **驭算软件栈**：配套TopsRider 1.0软件平台，支持TensorFlow、PyTorch等主流框架
- **训练场景覆盖**：支持CNN、RNN、LSTM、BERT等常用训练模型，覆盖图像、流数据、语音等场景

---

## 产品定位

云燧T10是燧原科技的开山之作，对标NVIDIA V100，主打云端AI训练场景。作为国内最早量产的高性能AI训练卡，T10在2019年发布时填补了国产AI训练芯片的空白。

---

## 应用场景

- 大规模深度学习模型训练（GPT、BERT、ResNet等）
- 互联网推荐系统训练
- 金融风控模型训练
- 医疗影像AI训练
- 教育科研AI训练集群
