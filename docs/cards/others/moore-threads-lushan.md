# 摩尔线程 庐山（第五代「花港」架构 · 图形渲染 + AI）

## 产品概述

**庐山**是摩尔线程基于**第五代「花港」架构**打造的高性能**图形渲染芯片**，计划 **2026 年内上市**。

庐山的关键突破是**首次在国产 GPU 上搭载硬件级光线追踪加速引擎**——此前摩尔线程的光追能力主要依赖软件路径与通用计算单元模拟。同属花港架构、专注 AI 训推一体的姊妹产品「[华山](/docs/cards/others/moore-threads-huashan)」也将在年内量产，两者构成第五代架构的"图形 + 计算"双线布局。

摩尔线程在 2026 年半年度业绩说明会上表示，「庐山」相关 GPU 产品有望于年内上市，具体以公司正式产品发布信息为准。公司上半年研发投入 **7.69 亿元（同比 +38.16%）**，研发重点正是新一代「花港」架构下的华山、庐山芯片及相关应用。

## 摩尔线程全功能 GPU 路线

| 代际 | 架构 | 代表产品 | 状态 |
|------|------|----------|------|
| 第四代 | MUSA | [MTT S5000](/docs/cards/others/moore-threads-mtt-s5000) | **已量产**（云端训推主力） |
| 第四代 | MUSA | MTT S4000 / S3000 / S2000 | 已量产 |
| **第五代** | **花港** | **庐山（图形渲染）** | **年内上市** |
| **第五代** | **花港** | **华山（AI 训推一体）** | **年内量产** |

> **关键洞察**：摩尔线程是国产 GPU 中少数**同时覆盖图形渲染与 AI 计算**的厂商。庐山补的是光追这一图形短板，华山补的是训推一体这一算力短板——两条线共同支撑公司"全功能 GPU"的定位。
