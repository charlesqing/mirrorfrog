# 海光 深算四号 DCU (Hygon DCU 4)

## 产品概述

**海光深算四号 DCU** 是海光信息（688041.SH）「深算」系列 **GPGPU 协处理器的最新一代产品**，也是其「**CPU + DCU** 双芯协同」战略中的下一代 AI 算力核心。海光信息在 **2026 年 9 月 29 日**的投资者互动平台中确认：**新一代通用处理器与协处理器研发按计划推进，整体符合预期；深算四号预计 2026 年下半年推出**。

目前官方与市场已公开的信息集中在四项：**性能较上一代提升约 2 倍**、**支持 FP4**、**搭配第二代 Scale up 交换芯片 HySwitch 2.0**、**单芯片支持 192 卡互联**。其中 **192 卡互联**是本代最重要的架构指标——配合 HySwitch 2.0 的 Scale up 能力，**两层网络即可支撑数万卡规模的集群部署**，这意味着海光在大规模训练集群的组网能力上出现了台阶式提升，可与国内其他国产 AI 芯片厂商的千卡超节点路线正面竞争。

深算四号所在的 DCU 产品线具备成熟的软件生态底座。DCU 产品基于 **GPGPU 架构**，具备全精度计算能力，自研 **DTK** 异构计算平台与 **DAS** 人工智能基础软件栈**已集成超 2000 个算子、支持 100 余种主流 AI 工具**。截至 2026 年上半年，海光已完成与 **DeepSeek、Qwen3、混元、智谱等 400 余款主流大模型的全面适配优化，覆盖全球 99% 非闭源大模型**；DCU 产品线已在 **20 多个关键行业、300+ 应用场景**落地，服务客户覆盖政府部门、国有银行、三大运营商、互联网厂商等核心群体。2025 年 DCU 出货约 8 万张，同比增长约 150%，位列国产 AI 加速芯片头部。

海光信息近年的经营数据也为其新品提供了出货基础：**2026 年上半年营业收入 90.99 亿元，同比增长 66.52%；归母净利润 17.98 亿元，同比增长 49.69%**；第二季度净利润环比增长 61%；上半年研发投入 26.52 亿元，占营业收入比例达 **29.15%**，研发技术人员 3007 人、占员工总数 80.83%。

> ⚠️ **参数披露状态说明（重要）**：截至目前，海光信息**尚未公布深算四号的算力数值、显存容量、显存类型、显存带宽与 TDP 功耗**。本卡规格表中上述字段一律标注「**未公布**」，**不做任何推测性填充**。业界流传的 FP6 支持、十万卡集群等说法均来自非官方渠道，本卡不采信。官方口径中唯一可量化的性能表述是「**性能较上一代提升约 2 倍**」——需注意这是**相对倍数而非绝对算力**，且未说明对比基准的具体型号与测试口径。

## 关键特性

### 1. HySwitch 2.0 与 192 卡 Scale up 互联

- 深算四号搭配**第二代 Scale up 交换芯片 HySwitch 2.0**
- **单芯片支持 192 卡互联**——这是 DCU 产品线在 Scale up 方向的关键指标，显著高于前代的卡间互联规模
- **两层网络可支撑数万卡集群部署**，大幅降低大规模集群的网络层级与延迟开销
- Scale up（片间）与 Scale out（节点间）分层解耦，是国产 AI 芯片厂商普遍采用的集群扩展路线

### 2. 「CPU + DCU」双芯协同

- 海光是国内少数同时具备 **x86 高端通用处理器（CPU）与类 CUDA 生态协处理器（DCU）**研发与大规模商用能力的企业
- CPU 兼容 x86 指令集，生态成熟度优势显著；DCU 基于 GPGPU 架构，具备全精度计算能力
- 「双芯协同」使海光在整机 / 集群方案层面具备一体化交付能力

### 3. DTK + DAS 软件生态

| 层级 | 内容 |
|------|------|
| **异构计算平台** | **DTK**（DCU Toolkit），基于开源生态，支持主流 AI 工具 |
| **AI 基础软件栈** | **DAS**，已集成**超 2000 个算子** |
| **工具支持** | 支持**100 余种主流 AI 工具** |
| **模型适配** | 已完成 **DeepSeek、Qwen3、混元、智谱等 400 余款**主流大模型适配优化 |
| **覆盖率** | 覆盖**全球 99% 非闭源大模型** |
| **生态联盟** | 「**光合组织**」已聚合**超 6000 家**生态合作伙伴 |

### 4. 落地场景与客户覆盖

- 已在 **20 多个关键行业、300+ 应用场景**落地
- 客户覆盖政府部门、国有银行、三大运营商、互联网厂商等核心群体
- 已与**字节、腾讯、阿里、百度**等头部互联网厂商建立深度合作，共同开展技术联合研发与定制化服务
- 应用于大数据处理、人工智能、商业计算等领域
