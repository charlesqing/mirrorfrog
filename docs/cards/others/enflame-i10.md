# 燧原科技 云燧 i10

> 燧原科技首款人工智能推理加速卡，基于自研邃思1.0芯片，2020年12月发布，单槽设计，主打云端AI推理场景。

---

## 核心规格

| 规格 | 参数 |
|------|------|
| **架构** | 邃思1.0（DTU 数据流架构） |
| **制程** | 格芯 12nm FinFET |
| **TDP** | 150 W |
| **显存** | 16 GB HBM2（预估） |
| **显存带宽** | 512 GB/s（预估） |
| **FP32 算力** | 17.6 TFLOPS |
| **FP16 / BF16 算力** | 70.4 TFLOPS |
| **INT8 算力** | 140.8 TOPS（预估） |
| **接口** | PCIe 4.0 x16，**单槽** |
| **首发** | 2020-12-21 |
| **价格** | 未公开（预估 ¥25,000） |

---

## 技术亮点

- **单槽设计**：业界少数单槽高性能AI推理卡，可在1U服务器内部署8张，大幅提升推理密度
- **邃思1.0 芯片**：与云燧T10同款芯片，针对推理场景优化软件栈
- **驭算推理引擎**：配套TopsInference推理加速引擎，支持INT8/FP16混合精度推理
- **多场景覆盖**：适用于计算机视觉、自然语言处理、语音识别与合成、知识图谱等推理场景
- **高密度部署**：单槽设计使1U服务器可配置8张i10，推理吞吐量大幅提升

---

## 产品定位

云燧i10是燧原科技"训练+推理"产品矩阵中的推理端产品，单槽高密度设计是其最大特色。对标NVIDIA T4，主打云端AI推理场景。

---

## 应用场景

- 云端AI推理服务（CV、NLP、ASR/TTS）
- 互联网推荐系统推理
- 智慧城市视频分析
- 金融实时风控推理
- 边缘推理服务器
