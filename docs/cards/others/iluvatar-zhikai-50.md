# 天数智芯 智铠 50（低功耗边缘推理卡）

## 产品概述

**智铠 50（MR-V50）** 是天数智芯智铠系列的 **入门级低功耗推理加速卡**，**板级功耗仅 75 W**，采用**半长半高单槽 PCIe** 形态与**被动散热**设计，配备 **16 GB HBM2e** 显存，售价约 **1.5 万元**。

凭借 75 W 的低功耗与半高半长规格，智铠 50 可同时适配两类场景：
- **小型机房扩容**：无需改造供电与散热，直接插入存量服务器
- **工控机 / 边缘节点**：半高半长形态适配紧凑型工控机箱

视频处理能力是智铠 50 的另一亮点：**最大支持 128 路 H.264 1080P@30fps 视频解码**，并支持 H.264 / H.265 / VP9 / AVS2 格式的 JPEG 图像编解码（2000 / 500 帧 HD），适合智慧城市视频分析、内容审核等视频类推理负载。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | 天数智芯通用 GPU 架构 |
| **产品定位** | 边缘 / 工控轻量化推理 |
| **INT8** | **192 TOPS**（另有信源报 64 TOPS，存在口径冲突） |
| **显存容量** | **16 GB** HBM2e |
| **TDP** | 75 W（板级功耗） |
| **接口** | PCIe Gen4 ×16 |
| **散热方式** | 被动散热 |
| **板卡尺寸** | 半长半高单槽 PCIe 卡 |
| **视频解码** | 最大 128 路（H.264 1080P@30fps） |
| **图像编解码** | JPEG 解码 / 编码：2000 / 500 帧（HD） |
| **首发** | 2022 年 12 月（智铠系列） |
| **价格** | 约 **1.5 万元** |

> ⚠️ **口径冲突说明**：智铠 50 的整型算力在不同信源中存在 **192 TOPS** 与 **64 TOPS** 两种表述（相差约 3 倍），本站取券商调研纪要的 **192 TOPS** 并保留冲突标注。制程、FP16 / FP32 算力、显存带宽均未公开。请以天数智芯官方数据表为准。

## 适用场景分级

在 2026 年国产 PCIe 推理卡分级中，智铠 50 属于**第三梯队（边缘 / 工控轻量化，< 100–200 TOPS）**：

| 梯队 | 定位 | 代表型号 |
|------|------|----------|
| 第一梯队 | 云端大模型推理旗舰 | 昆仑芯 P800、昇腾 Atlas 300I A2、智铠 100 |
| 第二梯队 | 中高密度机房推理 | 昇腾双 310P、寒武纪思元 370、摩尔线程 MTT S4000 |
| **第三梯队** | **边缘 / 工控轻量化** | **智铠 50**、昇腾 310P 单卡、瑞芯微 RK1828 |

> 📌 **选型建议**：智铠 50 的核心竞争力是 **75 W 功耗 + 半高半长单槽 + 16 GB HBM2e + 128 路视频解码** 的组合，适合**存量服务器低成本扩容**与**工控 / 边缘盒子**。若追求单卡算力，应选择智铠 100 或第一梯队产品。
