# 灵汐科技 领启 KA200（类脑芯片）

## 产品概述

**灵汐科技（Lynxi）** 是一家专注类脑计算技术的科技公司，拥有清华大学 **"天机（Tianjic）"** 类脑芯片的核心技术与专利，是该成果从基础研究走向产业化的主体。2019 年 8 月，"天机"芯片作为世界首款异构融合类脑芯片登上《自然》（Nature）封面，可同时支持脉冲神经网络（SNN）与人工神经网络（ANN）。

灵汐科技推出的 **领启® KA200(-S)** 是 **全球首款量产商用的异构融合类脑芯片**，基于全新的 **存算一体 + 众核并行 + 异构融合** 架构，能高效支持深度学习神经网络、生物神经网络与大规模脑仿真。单芯片集成 **25 万神经元 / 2500 万突触**，可扩展至 **200 万神经元 / 20 亿突触**，支持混合精度（32 TOPS@INT8 / 16 TFLOPS@FP16），并可高效支持卷积脉冲神经网络（CSNN）等新型类脑算法。

相较于典型冯·诺依曼架构芯片，KA200 针对神经网络的连接稀疏性、事件稀疏性高度优化，脑仿真执行效率可提升百倍以上。灵汐基于 KA200 推出类脑模组（HM100）、加速卡（HP300）、边缘产品（HS140）及类脑服务器，落地脑科学、互联网、智慧电力、交通、金融等场景，2025 年还落地了国内首个类脑智算集群，支持大模型毫秒级推理。

## 关键特性
- **异构融合类脑架构**：同时支持 ANN（深度学习）与 SNN（脉冲神经网络）及两者混合，是世界首款量产商用融合类脑芯片路线。
- **存算一体 + 众核并行**：针对连接稀疏性/事件稀疏性优化，脑仿真效率较冯·诺依曼架构提升百倍。
- **大规模脑仿真能力**：单芯片 25 万神经元 / 2500 万突触，可扩展至 200 万神经元 / 20 亿突触。
- **混合精度**：支持 INT8 / FP16 / Binary spike 等多种精度，覆盖传统 AI 与类脑算法。
- **产品矩阵完整**：模组、加速卡、边缘产品到类脑服务器/智算集群全覆盖。
