# 摩尔线程 MTT S2000

> 摩尔线程首款全功能服务器GPU，基于自研MUSA架构，2022年7月发布，12nm制程，32GB显存，支持图形渲染、AI计算和视频编解码。

---

## 核心规格

| 规格 | 参数 |
|------|------|
| **架构** | MUSA（Moore Threads Unified System Architecture） |
| **制程** | 12 nm |
| **MUSA 核心** | 4096 个 |
| **TDP** | 200 W（预估） |
| **显存** | 32 GB GDDR6 |
| **显存带宽** | 448 GB/s |
| **FP32 算力** | 12 TFLOPS |
| **FP16 算力** | 48 TFLOPS（预估） |
| **INT8 算力** | 96 TOPS（预估） |
| **接口** | PCIe 4.0 x16，双槽 |
| **视频编解码** | 支持 H.264、H.265、AV1 多路高清编解码 |
| **首发** | 2022-07-05 |
| **价格** | 未公开（预估 ¥25,000） |

---

## 技术亮点

- **全功能GPU**：同时支持图形渲染、AI计算和视频编解码，是摩尔线程首款全功能服务器GPU
- **MUSA 自研架构**：完全自主知识产权的统一系统架构，支持DirectX、Vulkan、OpenGL等图形API
- **大容量显存**：32GB GDDR6显存，满足大语言模型和图形渲染的显存需求
- **多路视频处理**：支持AV1、H.264、H.265等多路高清视频编解码，适用于视频云场景
- **多元计算支持**：支持FP32/FP16/INT8等多种精度，可加速AI训练与推理

---

## 产品定位

MTT S2000是摩尔线程面向数据中心和服务器市场的首款全功能GPU，对标NVIDIA A10/A30。作为"元计算"算力底座，S2000支持图形渲染、AI计算和科学计算多元场景。
