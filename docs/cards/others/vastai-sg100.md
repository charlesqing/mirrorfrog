# 瀚博半导体 乾元SG100 (2023)

## 产品概述

**乾元SG100** 是瀚博半导体于 **2023年7月6日** 在2023世界人工智能大会上正式发布的**第二代GPU芯片**，采用 **7nm 先进制程**，是**集渲染、AI、视频于一体的全功能GPU**，具备业界领先的渲染性能，同时兼具低延时高吞吐的AI算力和强大的视频处理能力。

**定位**：**全功能GPU**（图形渲染 + AI 推理 + 视频处理），对标 NVIDIA A100 的部分场景，是中国**全功能GPU**的重要突破。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | 瀚博第二代GPU架构（乾元系列） |
| **制程** | **7nm**（TSMC） |
| **功能** | **渲染 + AI + 视频** 三合一 |
| **FP32 算力** | 未公开（推测 ~20 TFLOPS） |
| **FP16/INT8 算力** | 未公开（推测 ~200 TFLOPS FP16 / ~400 TOPS INT8） |
| **光线追踪** | 支持（硬件光追） |
| **视频编解码** | 强大视频处理能力（具体路数未公开） |
| **TDP** | 未公开（推测 200-300W） |
| **板卡形态** | 南禺系列（VG1600/VG1800/VG14） |
| **发布** | **2023-07-06**（2023世界人工智能大会） |
| **量产时间** | 2023-Q4 |
| **API 支持** | DirectX 11、OpenGL、Vulkan（Windows/Linux） |

> ⚠️ **规格说明**：SG100 的具体算力数值官方未完整公开，以上部分为基于公开报道的推测，以瀚博半导体后续官方数据表为准。
