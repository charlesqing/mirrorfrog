# 沐曦 曦云 C290

## 产品概述

**沐曦 曦云 C290** 是沐曦股份（MetaX）**曦云 C 系列**通用计算 GPU 的早期型号，采用沐曦自主知识产权的 **XCORE 1.0 架构及指令集**，以 **OAM 1.5** 加速模块形态交付，定位 **AI 训练与推理**。曦云 C 系列是沐曦的主力产品线（营收占比 97%+），基于自研 GPGPU 架构，配合全兼容 CUDA 生态的 **MXMACA® 软件栈**，可广泛应用于智算、通用计算与数据分析。

相比后续大规模量产的 **曦云 C500（2023）/ C550 / C600（2025）**，C290 属于同代 XCORE 1.0 家族的早期产品，公开规格资料极少。其算力区间可参考 XCORE 1.0 家族（如 C500：FP32 15–40 TFLOPS、INT8 480 TOPS、64GB HBM2e），但 **C290 的官方专属参数未公开**，下表以"未公开/推测"标注，避免编造。

## 关键特性

- **XCORE 1.0 自研架构**：标量 + 矢量 + 张量计算单元，多精度混合算力
- **OAM 1.5 形态**：开放加速模块，便于高密度服务器集成
- **MXMACA 软件栈**：API 层面兼容 CUDA 生态，支持 PyTorch/TensorFlow/PaddlePaddle
- **MetaXLink 互联**：卡间高速互连，支持多卡训练集群（具体端口数未公开）
