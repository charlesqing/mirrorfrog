# 摩尔线程 MTT S80

> 摩尔线程首款消费级游戏显卡，搭载完整"春晓"芯片，4096个MUSA核心，2023年11月发布，国产游戏显卡的代表作。

---

## 核心规格

| 规格 | 参数 |
|------|------|
| **架构** | MUSA（春晓芯片） |
| **制程** | 7 nm |
| **MUSA 核心** | 4096 个 |
| **GPU 频率** | 1.8 GHz |
| **TDP** | 255 W |
| **显存** | 16 GB GDDR6 |
| **显存位宽** | 256 bit |
| **显存带宽** | 448 GB/s |
| **FP32 算力** | 14.4 TFLOPS |
| **FP16 算力** | 57.6 TFLOPS（预估） |
| **INT8 算力** | 115.2 TOPS（预估） |
| **接口** | PCIe 5.0 x16 |
| **视频输出** | 支持 8K 超高清 / 1080P 360Hz |
| **首发** | 2023-11-11 |
| **价格** | ¥2,999（首发价） |

---

## 技术亮点

- **春晓芯片**：摩尔线程第二代GPU芯片，7nm制程，4096个MUSA统一计算核心
- **PCIe 5.0**：业界首批支持PCIe 5.0的消费级显卡，双向带宽达128GB/s
- **全功能GPU**：同时支持图形渲染、AI计算和视频编解码，基于同一套MUSA架构
- **DirectX 支持**：支持DirectX 11/12，可运行主流3D游戏
- **AI 推理能力**：FP16算力57.6 TFLOPS，可加速本地AI推理（如LLM推理）

---

## 产品定位

MTT S80是摩尔线程面向消费市场的首款游戏显卡，对标NVIDIA RTX 4060级别产品。作为"国产游戏显卡"的代表，S80在国产化替代和本地AI推理场景中具有独特价值。

---

## 应用场景

- 国产3A游戏（基于DirectX 11/12）
- 本地AI大模型推理（LLaMA、ChatGLM等）
- 8K视频播放和处理
- 图形渲染和CAD
- 国产操作系统（统信UOS、麒麟）图形加速
