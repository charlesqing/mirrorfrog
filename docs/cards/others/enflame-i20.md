# 燧原科技 云燧i20 (2022)

## 产品概述

**云燧i20** 是燧原科技于 **2022 年**发布的第二代**人工智能推理加速卡**，基于自研 **邃思2.5 芯片**打造，采用 **12nm 工艺**，面向数据中心推理场景，具有高性能高能效、模型覆盖面广、易部署易运维等特点，可广泛应用于计算机视觉、语音识别与合成、自然语言处理、搜索与推荐等推理场景。

**定位**：**AI 推理专用**（inference-optimized），与云燧T系列（训练专用）形成完整产品矩阵。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | 邃思2.5（燧原自研） |
| **制程** | **12nm**（成熟工艺，成本优势） |
| **FP16** | 未公开（推测 ~100 TFLOPS） |
| **INT8** | 未公开（推测 ~200 TOPS） |
| **显存容量** | 未公开（推测 16–32GB） |
| **显存带宽** | 未公开 |
| **TDP** | 200 W（推测） |
| **形态** | **PCIe 标准卡**（全高全长） |
| **互联** | 支持多卡推理 |
| **发布** | **2022 年** |
| **量产** | 2022 年起 |
| **软件栈** | 燧原智算软件栈（兼容 PyTorch/TensorFlow） |

> ⚠️ **规格说明**：云燧i20 的详细规格官方未完整公开，以上部分为推测值，以燧原科技后续官方数据表为准。

## 邃思芯片演进

| 芯片 | 制程 | 应用 | 产品 |
|------|------|------|------|
| 邃思1.0 | 12nm（推测）| 第一代 | 云燧T10、i10 |
| 邃思1.5 | 12nm | 第一代升级 | 云燧T20 |
| **邃思2.0** | **7nm** | 第二代训练 | **云燧T21** |
| **邃思2.5** | **12nm** | 第二代推理 | **云燧i20** |
| 邃思3.0（推测）| 7nm/5nm | 第三代 | 云燧T30（待发布）|

## 与云燧i10对比

| 指标 | 云燧i10 | **云燧i20** | 提升 |
|------|----------|----------------|------|
| 芯片 | 邃思1.x | **邃思2.5** | 新一代 |
| 模型覆盖 | 基础 | **更广** | 泛化支持能力增强 |
| 性价比 | 基准 | **更优** | 12nm 成熟工艺 |
| 供应链 | 基准 | **更稳定** | 12nm 产能充足 |

## 适用场景

- ✅ **计算机视觉推理**（检测/跟踪/分类）
- ✅ **语音识别与合成**
- ✅ **自然语言处理**（NLP 推理）
- ✅ **搜索与推荐**（互联网场景）
- ✅ **泛互联网/传统行业/新基建**
- ✅ **性价比敏感场景**（12nm 成本优势）
- ❌ **大模型训练**（推理专用卡）
- ❌ **超高算力需求**（训练卡更优）
