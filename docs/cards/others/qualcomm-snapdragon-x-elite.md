# Qualcomm Snapdragon X Elite (Oryon 12 核 NPU 45 TOPS)

## 产品概述

**Qualcomm Snapdragon X Elite** 是 Qualcomm 2023-10 Snapdragon Summit 发布的 **ARM 架构 PC 芯片**，**4nm TSMC** 制程，**12 核 Qualcomm Oryon CPU** @ 3.8 GHz（单/双核 boost 至 **4.3 GHz**），**Adreno GPU**（最高 4.6 TFLOPs），**Hexagon NPU 45 TOPS**（**Laptop NPU 之最**），**LPDDR5x 8448 MT/s 64GB 内存**、**135 GB/s 带宽**。AI 总算力 75 TOPS。**Microsoft Copilot+ PC 认证**（Recall、Live Captions、Cocreator 三大独占 AI 功能）。是 **首款**能在续航、性能、AI 三大维度挑战 Apple Silicon M2/M3 的 ARM Windows 芯片。

> **Oryon 架构**：Oryon 是 Qualcomm **收购 Nuvia**（2021 年，$1.4B）后自研的 ARM CPU 核心，**原 Apple Silicon 首席架构师 Gerard Williams III** 领衔设计。Oryon 目标是 **"在 ARM 上实现 x86 顶级性能 + Apple Silicon 能效"**。
