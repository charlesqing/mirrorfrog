# Moore Threads 摩尔线程 MTT S5000 (国产 GPU 训练)

## 产品概述

**摩尔线程（Moore Threads）** 是中国全功能 GPU 创业公司，**2020-10 成立**，创始人为原 NVIDIA 中国区高管 **张建中**。**MTT S5000** 是基于 **第四代 MUSA "平湖" 架构** 的训推一体 GPU 智算卡，**2025-02-12 公开参数**：**单卡 FP8 稠密 AI 算力 1000 TFLOPS**，**80GB 显存**，**1.6 TB/s 带宽**。配套自研 **MUSA** 统一系统架构 + **MUSIFY** 软件栈。

**战略定位**：相比华为昇腾专注 AI 训练，摩尔线程走**全功能 GPU** 路线（图形 + AI + 通用计算），是中国**对标 NVIDIA 的国产 GPU 创业公司**，与景嘉微、芯原微电子、燧原科技、壁仞科技并列为"国产 GPU 五虎"。

**2026 年 6–7 月最新动态**：完成对 MiniMax M3、智谱 GLM-5.2、阿里 Qwen3.5 的 Day-0 适配；**2026-07-06 完成美团万亿参数大模型 LongCat-2.0 的 Day-0 适配**，国产 AI 软件生态快速成熟。

**2026 年 10 月动态**：由摩尔线程建设运营的**无锡（惠山）国产智算中心**一期部署的 **2,000 张 MTT S5000** 于 6 月点亮后仅两个月即实现**满载运行**（2026-10-15 证券时报报道），刷新国内国产商用智算集群落地提速纪录。**Q3 财报（2026-10-28 披露）**：单季营收 15.52 亿元（同比 +1773.9%、环比 +55.4%），归母净利 4,926 万元、**扣非净利 2,007 万元首次转正**，盈利时点较原定 2027 年大幅提前；9 月与京东云宣布合作建设**十万卡全功能 GPU 集群**；中国移动移动云北京 Token 中心顺义节点亦部署 S5000。

## 关键特性

- **全功能 GPU**：图形 + AI + 通用计算（GPGPU）+ 光追
- **国产化率 60%**：HBM/显存来自三星/海力士，CPU 国产（兆芯），封装国产
- **多精度支持**：FP32 / FP16 / BF16 / INT8 / INT4
- **多卡互联**：MUSA Link 8 卡，784 GB/s 双向

- **缺点**：相比 NVIDIA H100 (989 BF16 TFLOPS) 算力 1/20，生态差距大

## 2026-11-13 补充：PD 分离进了生产环境

11 月 4 日起广州日报大洋网、三易生活报道，2026 人工智能+大会（GAI+C）上摩尔线程联合趋境科技与智谱发布「国产异构推理高品质 AI Token 工厂解决方案」。分工是：S5000 靠高密度算力与原生 FP8 负责计算密集的 Prefill，显存带宽更大的算力负责逐 token 生成的 Decode，趋境的 PD 异构推理系统做 KVCache 跨设备流转，把 Prefill 解耦成可独立供给、独立计费、独立优化的资源池。

方案给的实测是：平均生成速度超过 50 TPS、KV Cache 命中率超过 90%、稳定性 99.9%；由 3 至 4 台 S5000 组成的 Prefill 池，在同等生产服务标准下输入 Token 处理性价比超过国际先进算力方案。厂商称方案已在生产环境全面使用，承载头部模型企业的超大参数模型与高并发真实流量。

这几个数不能折算成单卡吞吐。发布方没给并发数、模型、序列长度、集群规模，也没给「性价比超过」的对比机型与每 Token 成本分母。50 TPS、90%、99.9% 是整套方案在生产流量下的指标，不是本卡规格。

> 口径说明：厂商发布与媒体转述，方案级指标，无第三方实测、无单卡可折算数值；本页规格表不改。选型要按指定并发与序列长度下的全栈吞吐和每 Token 成本评估，[TCO 计算器](/docs/tco-calculator) 里的口径比单卡峰值更接近这类方案。
