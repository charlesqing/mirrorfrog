# 天数智芯 智铠100 (MR100)

## 产品概述

**智铠100**（型号 **MR100** / **MR-V100**）是天数智芯于 **2022 年**发布的云端**通用 GPU 推理加速卡**，基于天数智芯自研通用 GPU 架构设计，采用 **7nm 工艺**，配备 **32GB HBM2E 显存**，支持 FP32/FP16/INT8 混合精度推理，单卡最高支持 **128 路 1080P@30fps 高清视频并发解码**，面向安防、互联网、金融、医疗、教育等 AI 推理场景。

**定位**：**AI 推理专用**（inference-optimized），与天垓系列（训练专用）形成完整产品矩阵。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | 天数智芯自研通用 GPU 架构 |
| **制程** | **7nm** |
| **FP32** | **24 TFLOPS** |
| **FP16** | **96 TFLOPS** |
| **INT8** | **192 TOPS** |
| **显存容量** | **32 GB HBM2E** |
| **显存带宽** | 未公开（推测 ~1 TB/s） |
| **TDP** | 275 W（推测） |
| **视频解码** | 单卡最高 **128 路 1080P@30fps**，支持 HEVC、AVC、VP9、AVS2 |
| **接口** | **PCIe Gen4 x16** |
| **发布** | **2022 年** |
| **量产** | 2022 年起 |
| **软件栈** | 天数智算软件栈（兼容 PyTorch/TensorFlow） |

> ⚠️ **规格说明**：TDP 和显存带宽为推测值（官方未完整公开），以天数智芯后续官方数据表为准。

## 天垓系列 vs 智铠系列

| 系列 | 定位 | 代表产品 | 发布时间 |
|------|------|----------|----------|

| **智铠系列** | 推理（Inference） | 智铠100（MR100）| 2022 年 |
| **智铠系列** | 推理（Inference） | 智铠200（MR200）| 2024 年（推测） |

## 适用场景

- ✅ **AI 推理即服务**（INT8 192 TOPS，高并发推理）
- ✅ **视频分析**（128 路 1080P 并发解码）
- ✅ **安防监控**（HEVC/AVC/VP9 多格式支持）
- ✅ **金融风控**（低延迟推理）
- ✅ **国产智算中心**（供应链安全）
- ❌ **大模型训练**（推理专用卡，算力不及训练卡）
