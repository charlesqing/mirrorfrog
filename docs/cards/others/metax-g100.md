# 沐曦 曦彩 G100

> 沐曦集成电路面向图形渲染场景的首款GPU芯片，基于自研XCORE 2.0架构，14nm制程，主打云游戏、云桌面等场景，目前处于研发阶段。

---

## 核心规格

| 规格 | 参数 |
|------|------|
| **架构** | XCORE 2.0（曦彩架构） |
| **制程** | 14 nm |
| **TDP** | 150 W（预估） |
| **显存** | 8 GB GDDR6（预估） |
| **显存带宽** | 256 GB/s（预估） |
| **FP32 算力** | 5 TFLOPS（预估） |
| **图形API** | DirectX 12、Vulkan、OpenGL（预估） |
| **视频编解码** | 支持 H.264、H.265、AV1（预估） |
| **接口** | PCIe 4.0 x16（预估） |
| **发布** | 2025-12（预估） |
| **价格** | 未公开 |

---

## 技术亮点

- **首款图形渲染GPU**：沐曦三大产品线（曦云C系列、曦思N系列、曦彩G系列）的收官之作
- **XCORE 2.0 架构**：自研图形处理架构，支持高性能图形渲染
- **云游戏/云桌面**：面向云游戏、云桌面、数字孪生等场景
- **全国产供应链**：从架构设计到制造封装，逐步实现全国产
- **兼容主流图形API**：支持DirectX、Vulkan、OpenGL等图形API

---

## 产品定位

曦彩G100是沐曦面向图形渲染市场的首款GPU产品，定位消费级图形渲染，对标NVIDIA T1000/T2000。作为沐曦三大产品线的收官之作，G100标志着沐曦完成"训推一体+AI推理+图形渲染"全场景覆盖。
