# 地平线 征程5 (Journey 5)

## 产品概述

**征程5（Journey 5 / J5）** 是 **地平线（Horizon Robotics）** 的第三代车规级 AI 芯片，于 **2021 年 7 月 29 日在上海举办的发布会** 上正式发布（同期启动"开放生态战略"），定位为**面向高等级智能驾驶的全场景整车智能中央计算芯片**。它是**首款实现前装量产的国产百 TOPS 级大算力智驾芯片**。

征程5 基于 **台积电 16nm** 工艺与地平线**第三代 BPU 架构"贝叶斯（Bayesian）"** 打造：单颗 AI 算力最高 **128 TOPS**，支持 **16 路摄像头** 感知计算，**典型系统功耗约 30W**。地平线在宣传中刻意淡化峰值 TOPS 而强调"真实计算性能"——发布时公布 **1283 FPS**，随后通过软件与编译器优化提升至 **1531 FPS**，前视感知**延迟低至 60ms**（同期多数产品约 150ms）。CTO 黄畅将其归纳为"FPS = 硬件架构 × 算法架构 × 软件架构"的联合优化结果。贝叶斯架构的核心手段是**灵活配置的近存计算**，极大优化内存占用与访存，从而在低功耗下取得高有效算力。

**车规与功能安全**：地平线是首家通过 TÜV ISO 26262 功能安全**流程**认证的中国 AI 芯片公司；征程5 于 2021 年 7 月获得 **SGS-TÜV ISO 26262 ASIL-B 功能安全产品认证**，按 **ASIL-B(D)** 打造，应用可满足 ASIL-D 要求。**2023 年 2 月 2 日**，征程5 获得中汽研华诚（CATARC）颁发的**业界首张"汽车 SoC 芯片可信安全产品认证"**。

**量产与市场**：**2022 年 9 月，征程5 随理想 L8 Pro 实现全球首发量产**（L8/L7 的 Pro 版）。此后陆续获得理想、比亚迪、上汽、长安、长城、一汽红旗、自游家、哪吒等车企定点，方案涵盖单 J5、双 J5 与多 J5。至 **2023 年 9 月出货量突破 20 万片**，累计获超 9 家车企 20 多款车型量产定点；行业统计其 **2024 年智驾域控芯片装机量约 26.9 万颗**。商业上，余凯公开表示其成本"不到英伟达 Orin（约 400 多美元）的一半"，性价比是其打入高阶智驾市场的关键。

> 📌 **代际反思**：地平线 CEO 余凯后来公开承认，征程5 在规划阶段对"自动驾驶端到端技术发展速度"的预判偏超前，导致**对 CPU 算力的预估不足**——这也是征程6 大幅强化 CPU（18 核 A78AE / 410k DMIPS）的直接动因。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | 地平线 BPU 贝叶斯（Bayesian，第三代 BPU），双核 BPU，近存计算设计 |
| **制程** | 台积电 TSMC 16nm |
| **CPU** | 8 × Arm Cortex-A55，约 26k DMIPS（部分资料记 30k） |
| **FP16 / BF16 算力** | 未公开（BPU 主要面向定点整型推理） |
| **INT8 算力** | **128 TOPS**（旗舰版本；部分资料将 96 TOPS 版本记为 J5、128 TOPS 版本记为 J5P） |
| **FP32 算力** | 未公开 |
| **真实计算性能** | **1531 FPS**（发布时 1283 FPS，经软件优化提升） |
| **感知延迟** | **60 ms**（前视感知端到端） |
| **显存容量** | 未公开（随域控方案配置） |
| **显存类型** | 未公开（车规级 LPDDR，官方未披露具体代际） |
| **显存带宽** | 未公开 |
| **TDP** | **约 30 W**（系统平均功耗；部分资料记 30–35W；96 TOPS 版本约 20W） |
| **互联** | 支持多芯片级联（单 J5 / 双 J5 / 多 J5 方案；Matrix 5 平台可达 512 TOPS） |
| **接口** | SoC 板载（智驾域控制器）；支持 16 路摄像头，ISP 支持 16+ 路 HD / 2+ 路 4K |
| **功能安全** | ISO 26262 ASIL-B 产品认证（按 ASIL-B(D) 设计，应用可满足 ASIL-D）；CATARC 可信安全认证（2023-02） |
| **其他计算单元** | 2 × ISP、2 × DSP、计算机视觉引擎、视频编解码单元 |
| **发布** | 2021-07（2021-07-29 上海发布会；2021-09-10 亦有公开发布活动） |
| **量产/上市** | **2022-09 随理想 L8 Pro 全球首发量产**；2023-09 出货突破 20 万片 |

> ⚠️ **规格不确定性**：**内存子系统（容量 / 类型 / 带宽）地平线从未公开披露**，本卡如实标注"未公开"。关于 **96 TOPS 与 128 TOPS 的关系**：2020 年预告阶段官方口径为"单芯片 96 TOPS"，2021 年正式发布时为 128 TOPS；第三方规格表（AlfaWiki）将两者分别列为 **J5（96 TOPS / 20W）** 与 **J5P（128 TOPS / 30–35W）** 两个变体。中文语境下"征程5"通常即指 **128 TOPS / 30W** 版本，本卡以此为准。发布日期在不同报道中有 2021-07-29 与 2021-09-10 两说（前者为技术发布会，后者为公开亮相），此处取 **2021-07**。

## 关键特性

- **首款前装量产的国产百 TOPS 级智驾芯片**：打破国产大算力智驾芯片量产空白
- **BPU 贝叶斯架构**：灵活配置的**近存计算**，极致优化内存占用与访存，实现高算力密度 + 高能效比
- **重"真实性能"而非峰值算力**：1531 FPS + 60ms 延迟，功耗仅为 Orin 的 1/6 ~ 1/9（官方对比口径）
- **低延迟工程优化**：金字塔核心、拼接光流预处理 + 单图极致优化（而非服务器式批量推理），显著降低时延
- **全场景中央计算**：一颗芯片覆盖辅助驾驶、领航驾驶（NOA）、自动驾驶与车内智能交互
- **16 路摄像头接入**：满足 360° 环视 + 前视 + 座舱多路视频需求
- **可级联扩展**：单/双/多 J5 方案；Matrix 5 域计算平台与 Matrix SuperDrive 全场景方案（512 TOPS，支持 11–19 路摄像头）
- **"可成长的芯片"**：硬件不变、软件架构持续升级，FPS 从 1283 提升至 1531+
- **业界首张汽车 SoC 可信安全认证**（CATARC，2023-02）+ ISO 26262 ASIL-B 产品认证
- **成本优势**：单价不到 NVIDIA Orin 的一半，性能定位接近

## 适用场景

- ✅ 高速 NOA / 领航辅助驾驶（单 J5 主力场景）
- ✅ L2+ / L2++ 行泊一体高阶智驾域控
- ✅ 双 J5 / 多 J5 方案支撑 L3–L4 级自动驾驶研发与运营车队
- ✅ 全场景整车中央计算（智驾 + 座舱感知融合）
- ✅ 国产化替代 NVIDIA Orin 的成本敏感项目
- ✅ CNN 类感知网络（ResNet / 检测 / 分割）高效推理
- ❌ 大参数 Transformer / VLA / 世界模型端侧部署（架构与 CPU 算力均受限，官方已由征程6 承接）
- ❌ 一段式端到端大模型城区智驾（需征程6P 级算力）
- ❌ 数据中心训练 / 通用 AI 推理
