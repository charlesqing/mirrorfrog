# Moore Threads 摩尔线程 MTT S3000 (2023)

## 产品概述

**MTT S3000** 是摩尔线程推出的**全功能服务器 GPU**，搭载自研 **春晓芯片**，基于 **第二代 MUSA 架构**打造，配备 **48GB GDDR6 显存**（推测），支持图形渲染、视频处理、深度学习完整 MUSA 软件栈，可为数据中心、智算中心提供训推一体算力支持。

**定位**：**全功能服务器 GPU**（图形 + 计算），面向数据中心和智算中心部署。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | 自研 **春晓芯片**（第二代 MUSA 内核架构） |
| **制程** | 未公开（推测 7nm） |
| **FP32** | 未公开（推测 ~20 TFLOPS） |
| **TF32** | 未公开（推测 ~40 TFLOPS） |
| **INT8** | 未公开（推测 ~160 TOPS） |
| **FP16/BF16** | 支持（具体数值未公开） |
| **显存容量** | **48 GB GDDR6**（推测，与 S4000 相近） |
| **显存带宽** | 未公开（推测 ~700 GB/s） |
| **TDP** | 400 W（推测） |
| **互联** | **MTLink**（多卡高速互联） |
| **接口** | PCIe 4.0/5.0（推测） |
| **发布** | **2023 年** |
| **量产** | 2023 年起 |
| **软件栈** | MUSA 软件栈（兼容 CUDA） |

> ⚠️ **规格说明**：MTT S3000 的详细规格官方未完整公开，以上部分数值为推测值，以摩尔线程后续官方数据表为准。

## MUSA 架构演进

| 架构 | 芯片 | 代表产品 | 发布 |
|------|------|----------|------|
| 第一代 MUSA | 春晓（初代）| MTT S80（消费级）| 2022 |
| **第二代 MUSA** | **春晓（改进）** | **MTT S3000** | **2023** |
| 第三代 MUSA | 曲院 GPU | MTT S4000 | 2023.12 |

## 与 MTT S4000 对比

| 指标 | **MTT S3000** | MTT S4000 | 差异 |
|------|----------------|-------------|------|
| 架构 | 第二代 MUSA（春晓）| 第三代 MUSA（曲院 GPU）| S4000 更新 |
| FP32 | 未公开 | **25 TFLOPS** | S4000 数值公开 |
| 显存 | 48GB GDDR6（推测）| 48GB GDDR6 | 相同 |
| 定位 | 全功能服务器 GPU | 大模型智算加速卡 | S4000 更专注训练 |
| 发布 | 2023 年 | 2023.12 | 同期 |

## 全功能 GPU 特性

MTT S3000 作为**全功能 GPU**，同时支持：

| 能力 | 说明 |
|------|------|
| **AI 计算** | 深度学习训练/推理（MUSA 软件栈） |
| **图形渲染** | OpenGL/Vulkan/DirectX 兼容 |
| **视频处理** | 硬件编解码（多格式支持） |
| **显示输出** | 数据中心 GPU 标准显示接口 |

## 适用场景

- ✅ **数据中心 GPU 虚拟化**（全功能支持）
- ✅ **图形渲染 + AI 混合负载**
- ✅ **国产智算中心**（春晓芯片，供应链安全）
- ✅ **CUDA 生态迁移**（MUSA 兼容层）
- ❌ **超高算力需求**（规格未完全公开，推测低于 S4000）
- ❌ **大规模训练集群**（MTLink 待验证）
