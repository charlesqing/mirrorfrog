# SambaNova SN40L

## 产品概述

SambaNova SN40L 是基于**可重构数据流（RDU - Reconfigurable Dataflow Unit）**架构的 AI 加速器，**不是传统指令式架构**。SN40L 提供完整 **8 节点系统**（SN40L-8），适合企业级 LLM 部署。

## 核心规格

| 项目 | 参数 |
|------|------|
| **架构** | RDU（可重构数据流） |
| **制程** | TSMC 7nm |
| **显存** | 64 GB HBM3 |
| **FP32 算力（估算）** | 100 TFLOPS |
| **INT8 算力（估算）** | 200 TOPS |
| **系统** | SN40L-8（8 节点） |
| **互联** | SambaNova 自研（Coherent Memory） |

## 关键特性

- **可重构数据流**：编译器映射数据流
- **Coherent Memory 跨节点**
- **企业级一体机**：开箱即用
- **多租户支持**

## 适用场景

- 企业级 LLM 私有部署
- 大模型推理
- 多模型多租户
