# 天数智芯 天垓 300 (BI-V300)

## 产品概述

**天垓 300** 是天数智芯（Iluvatar CoreX，9903.HK）**新一代自研架构的首款产品**，也是公司通用 GPU 产品线「天垓」训练系列的最新旗舰。**2026 年 7 月 19 日，天数智芯在 2026 世界人工智能大会（WAIC 2026）期间正式发布**。这是天数智芯自 2021 年天垓100 发布以来，时隔五年的旗舰级产品迭代。

芯片基于天数智芯**自研的 SIMT 通用计算架构**，集成**超过 1000 亿个晶体管**、**超过 200 个 AI 计算核心**（每个核心配备独立高速缓存与数据通路），单芯片 **FP16 算力突破 1000 TFLOPS、INT8 算力达到 2000 TOPS 以上**，采用 **7nm 制程**，典型功耗控制在 **600W 以内**。产品支持 **FP4、FP8** 等多种精度及 MMA、DPX、FMA 等指令集，同步推出 **PCIe 板卡与 OAM 模组**两种形态。

与前代「堆算力」的思路不同，天垓300 的差异化重点落在**底层算力向实际 Token 产出的转化效率**上。官方披露的实测口径包括：不同精度下 **Attention 效率超过 90%**；**64k 上下文**场景 Attention 效能较 Hopper 架构方案**高约 10%**；DeepSeek V4 MoE 场景计算效率**突破 70%**，推理平均效能高于 Hopper 方案 10%；在 Qwen、GLM、Kimi、DeepSeek 等主流模型测试中**首字延迟较 Hopper 方案降低约 20%**；Decode 阶段平均通信延迟**降低约 13%**。官方整体定位为**对标并超越 Hopper 架构**的国际主流方案。

值得注意的是，摩根士丹利在 WAIC 期间的供应链调研中记录，天垓300 的 **Prefill 与 Decode 性能超过 NVIDIA H100**（公司口径），但**管理层同时承认整体仍落后 Blackwell 一代**。天数智芯已规划**下一代天垓 400 于 2027 年流片**，明确对标 Blackwell。

> ⚠️ **HBM 类型分歧说明**：关于天垓300 的访存介质存在两种说法——**百度百科条目记为 HBM3**，而**摩根士丹利供应链调研记为 HBM3E**。公司官方新闻稿与主流媒体（澎湃、南方+、上证报）均**未明确标注 HBM 代次**，仅公布 144GB 容量与约 4 TB/s 带宽。本卡采信**摩根士丹利供应链调研口径的 HBM3E**（理由：144GB / 约 4 TB/s 的组合更接近 HBM3E 的量产水平，且该口径来自独立第三方调研），但保留分歧说明，请以厂商最终数据表为准。

## 关键特性

### 1. SIMT 通用计算架构：回归计算本质

- 天垓300 是天数智芯**新一代自研架构的首款产品**，从零构建的 SIMT 架构**可高效支持标量、矢量、张量多种计算类型**
- 官方强调「**不局限于 Transformer 架构**」，除 Attention、FFN、MoE 外，还可适配**矩阵求解、动态规划、稀疏计算、数字孪生**等任务
- 三类专属指令扩展：
  - **ixSMEX**：提高数据复用率，减少重复访存
  - **ixDPX**：将动态规划中原本需要六条指令完成的计算**压缩至一条**
  - **ixTrans**：无损矩阵转置，降低存储冲突与显存开销

### 2. 官方实测效能口径（vs Hopper 方案）

| 测试维度 | 天垓300 表现 |
|----------|--------------|
| **Attention 效率** | 不同精度下超过 90%，优于 Hopper 主流方案 |
| **64k 上下文 Attention 效能** | 高于 Hopper 方案约 10% |
| **DeepSeek V4 MoE 计算效率** | 突破 70%，综合训练效能与性价比优于 Hopper 方案 |
| **推理平均效能** | 高于 Hopper 方案约 10% |
| **首字延迟**（Qwen / GLM / Kimi / DeepSeek） | 较 Hopper 方案降低约 20% |
| **平均通信延迟**（Decode 阶段） | 降低约 13% |
| **GLM 5.2 Decode 效能** | 较 Hopper 方案提升 10% |
| **Cosmos3 世界模型推理效能** | 较 Hopper 方案高 10% |

### 3. 三类智能的产品设计主线

天数智芯 AI 与加速计算负责人单天逸将 AI 演进划分为三类，并以此作为天垓300 的设计主线：

- **信息智能**（理解与生成信息）：重点优化 **Attention 与 MoE**，通过提升矩阵计算与向量计算的并行效率减少数据读写等待与冗余计算；针对 MoE 的专家调度与数据路由损耗做算法与硬件协同优化
- **行动智能**（规划与执行）：强化 **PD 分离**能力，对 Prefill 与 Decode 阶段做差异化优化；在 Decode 阶段针对「高频、多卡、小数据量通信」特征降低协议开销、优化链路路径与数据流转机制
- **探索智能**（建模、预测与探索）：坚持回归计算本质，支持标量 / 矢量 / 张量计算，覆盖 FP4、FP8 等精度及 MMA、DPX、FMA 指令，服务新材料发现、气象预测、数字孪生、世界模型等场景

### 4. 生态与部署

- 天垓300 **已具备规模化应用条件**，与国内云厂商、服务器厂商、互联生态及超节点系统完成深度适配，支持从单机到规模化集群的部署

## 天垓300 IXL144 超节点（2026-10 工博会首展）

**2026 年 10 月 12 日**，第二十六届中国国际工业博览会（上海）首设「国芯展」，天数智芯首次展示系统化超节点布局中的首个方案 **天垓300 IXL144**：

| 项目 | 参数 |
|------|------|
| **单机柜集成** | **144 颗 GPU + 18 颗 CPU**（业界最高密度单机柜 GPU 超节点） |
| **整机显存** | 约 **10.1 TB** |
| **部署形态** | 适配行业通用标准的单机柜形态，现有机房条件即可部署，支持一次规划、弹性分步扩容 |
| **成本口径** | 每百万有效 Token 成本较国际主流方案**下降约 40%**（公司测算口径） |
| **商业进展** | 天垓系列已达**万卡级商业部署**，覆盖 30 余个行业、380 余家商业化客户、落地超 1,000 个行业项目 |

> 📌 口径说明：「业界最高密度」「成本下降 40%」均为天数智芯在公司发布与工博会现场口径，无第三方独立验证。同期工博会上，沐曦展出曦景 S600 超节点（单机柜 64 卡全互连）、燧原与中兴合作展出云燧 ESL64-O 正交架构超节点——国产超节点已在 2026 下半年成为展示重心。
- 天数智芯自 2018 年起持续完善软件栈，目前已开发**近百个加速库**，形成覆盖**通信、编译、驱动、量化、性能分析**的工具体系
- 同步支持全球主流大模型框架、模型及关键加速组件，减少客户在迁移、适配与性能调优中的重复投入
- 依托 **DeepSpark 开源社区**，与合作伙伴共建应用与评测平台
- 下一代**天垓 400 计划 2027 年流片**，对标 NVIDIA Blackwell

## 适用场景

- ✅ **大模型训练与推理**（Attention / MoE 专项优化，FP4 / FP8 低精度支持）
- ✅ **PD 分离推理架构**（Prefill / Decode 差异化优化，首字延迟降低约 20%）
- ✅ **Agent 应用**（智能编程、办公助手、业务自动化，强调响应及时性与交互流畅度）
- ✅ **长上下文任务**（64k 上下文 Attention 效能高于 Hopper 方案约 10%）
- ✅ **科学计算与仿真**（矩阵求解、动态规划、稀疏计算、数字孪生）
- ✅ **世界模型与预测类应用**（Cosmos3 世界模型推理效能较 Hopper 方案高 10%）
- ❌ 追求 Blackwell 级别峰值算力的工作负载（官方承认整体仍落后 Blackwell 一代）
