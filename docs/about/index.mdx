# 关于 MirrorFrog

MirrorFrog 是一个开源项目，致力于整理和导航各类 AI 加速芯片的驱动、文档与 SDK 资源。

## 项目初衷

AI 计算卡的驱动和文档散布在各厂商的不同页面，版本多、路径深，查找起来非常麻烦。MirrorFrog 将这些信息集中整理，帮助 AI 开发者和运维人员快速定位所需内容。

## 数据来源

数据来源于各厂商官网及开发者中心公开信息，由人工整理维护。我们尽力保证信息的准确性和时效性，但不对因使用本站信息导致的任何问题承担责任。
