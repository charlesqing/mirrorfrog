# IPU 智能处理器

IPU（Intelligence Processing Unit）是 Graphcore 独创的 AI 加速器架构，采用大量独立处理器内核以 MIMD 方式并行工作，与 GPU 的 SIMT 思路截然不同，为 AI 计算提供了一种全新的硬件范式。每个 IPU 核心拥有独立的本地 SRAM 内存，无需依赖外部 DRAM 或缓存一致性协议，彻底消除了传统 GPU 架构的访存瓶颈和数据搬运能耗。IPU 在图神经网络、推荐系统和稀疏计算场景中表现突出，在特定科学计算和组合优化问题上也有独特优势，尤其适合处理 GPU 不擅长的非规则数据结构。Graphcore 提供 Poplar SDK 和 Paperspace 云服务，支持 PyTorch 和 TensorFlow 框架。选购 IPU 需评估其在目标模型上的适配度和软件生态成熟度，对于图计算和稀疏模型有特殊需求的团队，IPU 提供了 GPU 之外的有力选择。
