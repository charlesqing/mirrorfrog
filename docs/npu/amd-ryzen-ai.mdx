# AMD Ryzen AI NPU

**厂商**: AMD

**分类**: NPU 神经网络处理器

**架构**: XDNA 2

## 简介

AMD Ryzen AI 是高通后集成在 AMD Ryzen 7040/8040/9000 系列处理器中的 NPU。基于 XDNA 架构，支持 ONNX Runtime 和 DirectML 加速推理，适合轻薄本上的 AI 应用。

## 规格参数

| 型号 | 算力 | 显存/内存 | 接口 | TDP | 制程 |
|------|------|-----------|------|-----|------|
| Ryzen AI 300 (Strix) | 50 TOPS (INT8) | LPDDR5X (共享) | 集成 SoC | 15-54W | 4nm |
| Ryzen AI 200 | 16 TOPS (INT8) | LPDDR5X (共享) | 集成 SoC | 15-28W | 4nm |

## 快速安装

### Windows 11

Ryzen AI NPU 通过 Windows 11 驱动和 ONNX Runtime 自动激活，无需额外安装。确保系统已更新。

```powershell
# 验证 NPU 可用 (通过 DirectML)
python -c "import onnxruntime as ort; print(ort.get_available_providers())"
```

## 代码示例

### Python (ONNX Runtime NPU)

```python
import onnxruntime as ort

# 使用 DirectML / NPU 后端
session = ort.InferenceSession("model.onnx", providers=['DmlExecutionProvider'])
results = session.run(None, {'input': input_data})
```

## 架构特色

- **XDNA 2 架构**: AMD 第二代 NPU 架构，50 TOPS 算力满足 Copilot+ PC 要求
- **AI PC 定位**: 面向日常 AI 助手任务（背景模糊、语音增强、文本生成）
- **CPU+NPU+GPU 协同**: 三大计算单元协同工作，NPU 处理低功耗常驻 AI 任务
