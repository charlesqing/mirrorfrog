# 芯擎科技 龍鹰系列

**厂商**: 芯擎科技 (Nexchip)

**分类**: 边缘计算 / 自动驾驶

**架构**: ARM + NPU

## 简介

专注于车载高端芯片。其旗舰芯片内置高算力NPU，专为智能座舱和自动驾驶场景的AI推理任务设计。

## 规格参数

| 型号 | 算力 | 显存/内存 | 接口 | TDP | 制程 |

| 龍鹰一号 | 8 TOPS (INT8) | 8GB LPDDR5 | 车规级 SoC | 15W | 7nm |
| 龍鹰二号 | 16 TOPS (INT8) | 16GB LPDDR5 | 车规级 SoC | 20W | 7nm |

## 快速安装

### Linux (车载系统)

```bash
# 1. 下载芯擎 SDK（需注册开发者账号）
# 访问 https://www.nexchip.com.cn/ 获取 SDK

# 2. 设置环境变量
export NEXCHIP_SDK_PATH=/opt/nexchip-sdk

# 3. 验证 NPU
npu-info
```

## 代码示例

### C/C++ (车载 NPU 推理)

```c
#include <nexchip_npu.h>

// 初始化 NPU 推理引擎
npu_handle_t handle;
npu_init(&handle, NPU_MODEL_AUTO);

// 执行推理
npu_tensor_t input = npu_create_tensor(input_data, dims);
npu_tensor_t output = npu_infer(handle, input);

// 释放资源
npu_release(handle);
```

## 架构特色

- **ARM + NPU 异构**: CPU 与 NPU 深度集成，低功耗下车载实时推理
- **车规级认证**: 通过 AEC-Q100 Grade 2，满足严苛车载环境要求
- **统一内存架构**: CPU 和 NPU 共享 LPDDR5，减少数据搬运开销
