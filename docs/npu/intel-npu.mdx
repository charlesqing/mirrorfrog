# Intel NPU (AI Boost)

**厂商**: Intel

**分类**: NPU 神经网络处理器

**架构**: Gaudi NPU Core / Movidius

## 简介

Intel Core Ultra 处理器内置的 NPU（AI Boost），用于低功耗 AI 推理加速。支持 OpenVINO 框架，适合轻薄本和边缘设备上的 AI 工作负载。

| 型号 | 算力 | 显存/内存 | 接口 | TDP | 制程 |
|------|------|-----------|------|-----|------|
| Core Ultra 200V | 48 TOPS (INT8) | LPDDR5X (共享) | 集成 SoC | 17-45W | Intel 4 |
| Core Ultra (Meteor Lake) | 12 TOPS (INT8) | LPDDR5X (共享) | 集成 SoC | 28W | Intel 4 |
| Movidius Myriad X | 4 TOPS (INT8) | 512MB LPDDR4 | USB 3.0 | 1.5W | 16nm |

## 快速安装

### Windows 11

Intel NPU 通过 OpenVINO 运行时自动使用，确保安装最新驱动。

```powershell
# 安装 OpenVINO
pip install openvino

# 验证 NPU 可用
python -c "from openvino import Core; core = Core(); print(core.available_devices)"
```

## 代码示例

### Python (OpenVINO NPU)

```python
from openvino import Core
from openvino.runtime import Model

# 检测 NPU 设备
core = Core()
print(f"Available devices: {core.available_devices}")  # 包含 'NPU'

# 加载并编译模型到 NPU
model = core.read_model("model.xml")
compiled = core.compile_model(model, "NPU")

# 推理
output = compiled(input_data)
```

## 架构特色

- **Intel NPU Core**: 基于 Gaudi 技术的低功耗 NPU 核心，面向 AI PC 的日常 AI 任务
- **Movidius VPU**: 面向边缘视觉推理的独立 VPU，适合摄像头/机器人
- **OpenVINO**: Intel 统一推理框架，自动选择 CPU/GPU/NPU 最佳后端
