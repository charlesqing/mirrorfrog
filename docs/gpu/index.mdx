# GPU 图形处理器

GPU 因高度并行的架构，成为深度学习训练和推理的主力硬件。NVIDIA CUDA 生态最为成熟，搭配 cuDNN、TensorRT 和 Triton Inference Server 等工具链覆盖了从研究到部署的全流程。AMD ROCm 在开源社区快速追赶，MI300X 等产品在推理性价比上表现突出，逐渐获得更多框架原生支持。Intel 通过 OpenVINO 和 Arc 系列布局 AI 推理市场，侧重边缘和客户端场景。消费级 GPU 适合个人开发者实验和小批量推理，数据中心级 GPU（如 H100、MI300X、Intel Gaudi 3）则支撑大规模训练集群。苹果 M 系列统一内存架构为端侧推理带来独特优势，大模型本地运行体验领先。国产方面，摩尔线程、壁仞科技、沐曦、天数智芯、昆仑芯、平头哥、景嘉微和瀚博半导体均推出产品，生态逐步完善，在信创和智算中心场景有广泛应用前景。
