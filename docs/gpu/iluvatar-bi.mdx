# 天数智芯 BI-150/BI-V150

**厂商**: 天数智芯 Iluvatar

**分类**: GPU 图形处理器

**架构**: 天垓架构

## 简介

天数智芯（Iluvatar）国产 GPU，BI-150 为云端训练推理卡，BI-V150 为新一代产品。支持 CUDA 兼容生态，2025 年营收 10.34 亿元，已登陆港股。

## 规格参数

| 型号 | 算力 | 显存/内存 | 接口 | TDP | 制程 |
|------|------|-----------|------|-----|------|
| 天垓 150 (BI-V150) | 256 TFLOPS (FP16) / 384 (INT8) | 64GB HBM2e (1.6 TB/s) | OAM | 350W | 7nm |
| 天垓 100 (BI-V100) | 147 TFLOPS (FP16) / 295 (INT8) | 32GB HBM2 (1.2 TB/s) | PCIe 4.0 | 250W | 7nm |
| 智铠 100 | 200 TOPS (INT8) | 32GB GDDR6 | PCIe 4.0 | 150W | 12nm |

## 快速安装

### Linux

```bash
# 1. 安装天数智芯驱动
sudo rpm -ivh iluvatar-driver-*.rpm
# 2. 安装 SDK
tar -xzf iluvatar-sdk-*.tar.gz && sudo ./install.sh

# 3. 验证
iluvatar-smi
```

## 架构特色

- **天垓架构**: 天数智芯自研 GPGPU 架构，兼容 CUDA 编程模型
- **智铠系列**: 面向低功耗推理场景的紧凑型加速卡
- **国产化生态**: 支持主流国产操作系统 (银河麒麟/统信 UOS)
