# 阿里平头哥 真武 PPU

**厂商**: 阿里巴巴 Alibaba

**分类**: GPU 图形处理器

**架构**: 平头哥 RISC-V

## 简介

阿里巴巴旗下平头哥半导体（T-Head），真武810E PPU（专用处理器）采用5nm工艺，性能比肩 NVIDIA H20。**2026年1月正式发布，累计出货47万颗，服务400+客户**，覆盖阿里千问系列模型训练和推理。含光 800 AI 推理芯片为早期产品。2025 年出货约 26.5 万颗，国产第二梯队。

## 架构特色

- **RISC-V + AI 扩展**: 平头哥自研 RISC-V 处理器，添加 AI 向量扩展指令
- **端侧定位**: 主要面向物联网和边缘设备 AI 推理
- **开源生态**: 依托 RISC-V 开源生态，THead 提供完整工具链
