# 壁仞科技 BR100/BR20X

**厂商**: 壁仞科技 Biren

**分类**: GPU 图形处理器

**架构**: 壁仞 Biren

## 简介

壁仞科技（Biren）大算力 Chiplet GPU。BR100（INT8 2048 TOPS，PCIe 5.0）为主力产品，BR20X 下一代芯片计划 2026 年推出，保持训练优势同时优化推理场景。2048 卡光互联 GPU 超节点已在国家级算力平台部署。

## 规格参数

| 型号 | 算力 | 显存/内存 | 接口 | TDP | 制程 |
|------|------|-----------|------|-----|------|
| BR100 | 256 TFLOPS (FP32) / 1,024 (BF16) / 2,048 (INT8) | 64GB HBM2E | OAM (PCIe 5.0) | 550W | 7nm |
| BR104 | 128 TFLOPS (FP32) / 512 (BF16) / 1,024 (INT8) | 32GB HBM2E | PCIe 4.0 | 250W | 7nm |

## 快速安装

### Linux

```bash
# 1. 安装壁仞驱动
sudo rpm -ivh biren-driver-*.rpm
# 或 DEB 系统
sudo dpkg -i biren-driver_*.deb

# 2. 验证
biren-smi
```

> 受出口管制影响，驱动和 SDK 获取渠道有限。

## 代码示例

### Python (壁仞 BIREN CUDA 兼容)

```python
import torch
# BR100 使用 CUDA 兼容后端
assert torch.cuda.is_available()

```

## 架构特色

- **壁仞自研架构**: 采用 Chiplet 设计，高算力和高带宽互联
- **CUDA 兼容策略**: API 层兼容 CUDA，便于现有 CUDA 应用迁移
- **出口管制**: BR100 被列入美国出口管制清单，影响商业化进程
