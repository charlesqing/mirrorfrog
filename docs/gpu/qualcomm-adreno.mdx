# Qualcomm Adreno GPU

**厂商**: Qualcomm

**分类**: GPU 图形处理器

**架构**: Adreno

## 简介

Qualcomm Adreno GPU 内置于骁龙（Snapdragon）SoC 中，支持 Vulkan、OpenCL、OpenGL ES 等图形和计算 API。适用于移动端和边缘设备的 GPU 加速计算。

## 规格参数

| 型号 | 算力 | 显存/内存 | 接口 | TDP | 制程 |
|------|------|-----------|------|-----|------|
| Adreno 830 (SD 8 Elite) | 12 TFLOPS (FP16) | LPDDR5X (共享) | 集成 SoC | 10W | 3nm |
| Adreno 750 (X Elite) | 8.5 TFLOPS (FP16) | LPDDR5X (共享) | 集成 SoC | 23W | 4nm |

## 快速安装

### Android (通过 Qualcomm AI Engine)

```bash
# 使用 QNN (Qualcomm Neural Network) SDK
# 从 Qualcomm Developer Network 下载
# 编译并部署 TFLite/QNN 模型
adb push model.dlc /data/local/tmp/
adb shell snpe-qlc-run --container /data/local/tmp/model.dlc
```

### Windows on Snapdragon

直接安装 Windows ARM64 驱动即可使用 Adreno GPU。

## 代码示例

### Python (QNN / TFLite)

```python
# Android 端通过 TFLite 使用 Adreno GPU 加速
import tflite_runtime.interpreter as tflite

interpreter = tflite.Interpreter(
    model_path="model.tflite",
    experimental_delegates=[tflite.load_delegate('libGpuDelegate.so')]
)
interpreter.allocate_tensors()
```

## 架构特色

- **Adreno GPU**: Qualcomm 移动/PC 端 GPU，集成在 Snapdragon SoC 中
- **Hexagon NPU 协同**: Adreno GPU 与 Hexagon DSP 协同提供 AI 加速
- **Snapdragon X Elite**: 面向 Windows on ARM 的 PC 级 AI 处理

## 模型兼容性

| 模型/框架 | 支持情况 | 备注 |
|-----------|----------|------|
| TFLite | ✅ GPU 委托 | Android 端主力 |

| ONNX Runtime | ✅ | WinML / QNN 后端 |
| Stable Diffusion | ⚠️ | 移动端受限 |
