# 沐曦 曦云 C500/C600

**厂商**: 沐曦 MetaX

**分类**: GPU 图形处理器

**架构**: 沐曦MACA

## 简介

沐曦（MetaX）国产 GPU，曦云 C 系列专注云端训练与推理。曦云 C600 基于全国产工艺，集成大容量显存与多精度混合算力，支持 MetaXLink 超节点扩展，内置 ECC/RAS 安全模块。累计销量超 5.5 万颗，2025 年营收 16.44 亿元。

## 规格参数

| 型号 | 算力 | 显存/内存 | 接口 | TDP | 制程 |
|------|------|-----------|------|-----|------|
| 曦云 C600 | 待公布 (FP8) | 144GB HBM3e | OAM | 待公布 | 7nm (国产) |
| 曦云 C500 | 280 TFLOPS (FP16) / 560 (INT8) | 64GB HBM2e (1.8 TB/s) | OAM | 450W | 7nm |
| 曦思 N100 | 80 TFLOPS (FP16) / 160 (INT8) | 16GB GDDR6 | PCIe 4.0 | 75W | 12nm |

## 架构特色

- **MACA 架构**: 沐曦自研 GPU 计算架构，面向 AI 训练和推理
- **CUDA 兼容**: API 层兼容 CUDA 编程模型，降低迁移成本
- **全栈自主**: 硬件、驱动、编译器、库全栈自主研发
