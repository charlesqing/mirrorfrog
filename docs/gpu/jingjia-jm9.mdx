# 景嘉微 JM9 系列

**厂商**: 景嘉微 Jingjia Micro

**分类**: GPU 图形处理器

**架构**: JM9

## 简介

景嘉微（Jingjia Micro）国产 GPU，军工起家，JM9 系列覆盖图形渲染+轻量 AI 加速。景宏系列智算模块面向数据中心。民用 AI 加速刚起步，军用/工控订单稳定。

## 快速安装

### Linux / Windows

安装景嘉微驱动和 SDK（从官方获取后）：

```bash
sudo rpm -ivh jingjia-driver-*.rpm
```

> JM9 系列主要面向图形渲染场景，AI 计算能力有限。

## 代码示例

### C (JM9 API)

景嘉微 JM9 提供自研图形 API，主要通过 OpenGL 兼容层使用。AI 计算支持度有限，推荐使用景嘉微官方 SDK 文档。

```c
// JM9 图形渲染示例 (OpenGL 兼容)
#include <GL/gl.h>
glClear(GL_COLOR_BUFFER_BIT);
glBegin(GL_TRIANGLES);
glVertex3f(0.0f, 1.0f, 0.0f);
glVertex3f(-1.0f, -1.0f, 0.0f);
glVertex3f(1.0f, -1.0f, 0.0f);
glEnd();
```

## 架构特色

- **JM9 架构**: 景嘉微自研 GPU 架构，主要面向图形渲染，OpenGL 兼容
- **国产化定位**: 军工/政府领域国产替代，已完成国产操作系统适配
- **AI 能力**: AI 计算能力有限，不推荐作为 AI 加速方案
