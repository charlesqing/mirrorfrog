# Intel GPU

**厂商**: Intel

**分类**: GPU 图形处理器

**架构**: Xe HPC (Ponte Vecchio / Falcon Shores)

## 简介

Intel 集成显卡和独立显卡系列，包括 Arc A 系列、Arc B 系列（Battlemage）、Data Center GPU Max/Flex。通过 Intel oneAPI 统一编程模型进行加速计算。

## 规格参数

| 型号 | 算力 | 显存/内存 | 接口 | TDP | 制程 |
|------|------|-----------|------|-----|------|
| Max Series 1550 | 75 TFLOPS (FP32) | 128GB HBM2e | SXM | 300W | Intel 7 |
| Arc A770 | 20 TFLOPS (FP32) | 16GB GDDR6 | PCIe 4.0 | 225W | Xe HPG |

## 快速安装

### Linux (Intel GPU

```bash
# 1. 安装 Intel GPU 驱动
sudo apt install -y intel-opencl-icd intel-level-zero-gpu

# 2. 安装 IPEX (Intel Extension for PyTorch)
pip install intel-extension-for-pytorch

# 3. 验证
sycl-ls
```

## 代码示例

### Python (Intel IPEX)

```python
import torch
import intel_extension_for_pytorch as ipex

# 使用 Intel XPU 后端
x = torch.randn(1024, 1024).xpu()
y = torch.matmul(x, x)
print(f"Intel XPU matrix multiply: {y.shape}")
```

## 架构特色

- **Xe HPC 架构**: 统一计算架构，支持 AI 和 HPC 场景，Falcon Shores 为下一代产品
- **SYCL/oneAPI**: Intel 开放编程模型，替代 CUDA 的跨平台方案
- **IPEX**: Intel PyTorch 扩展，提供 XPU 后端加速

## 模型兼容性

| 模型/框架 | 支持情况 | 备注 |
|-----------|----------|------|
| PyTorch | ✅ IPEX | Intel 官方扩展 |
| OpenVINO | ✅ 原生 | Intel 推理优化工具链 |

| Stable Diffusion | ✅ | SYCL 后端 |
