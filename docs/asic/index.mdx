# ASIC 专用加速卡

ASIC（Application-Specific Integrated Circuit，专用集成电路）是当前 AI 加速芯片中能效比最高的方案。与 GPU 不同，ASIC 从架构层面针对特定计算模式（如矩阵乘、稀疏推理、Transformer）进行极致优化，适合大规模、高负载的部署场景。AWS Trainium 用于云端训练、Cerebras WSE 以晶圆级集成挑战传统集群、寒武纪思元系列覆盖端侧到云端。国产阵营也在快速追赶：海光 DCU 兼容 ROCm 生态，燧原云燧主打云端推理与训练，清微可重构架构兼顾灵活与效率。选择 ASIC 需考虑生态成熟度与特定工作负载匹配度。
