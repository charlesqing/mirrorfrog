# d-Matrix Corsair

**厂商**: d-Matrix (美国)

**分类**: ASIC 专用加速卡

**架构**: DCM (Digital Chiplet Matrix)

## 简介

d-Matrix Corsair 是美国 AI 推理芯片公司 d-Matrix 推出的数据中心级推理平台，基于数字存内计算技术，专为大规模 AI 推理工作负载设计。d-Matrix 通过将计算直接嵌入存储阵列，消除传统架构中的数据移动瓶颈，提供高能效的矩阵运算加速。

## 架构特色

- **DCM (数字 Chiplet 矩阵)**: 基于 chiplet 的模块化架构
- **存内计算**: 直接在存储阵列中执行矩阵运算，消除数据移动瓶颈
- **高能效推理**: 专为数据中心推理工作负载优化
- **可扩展设计**: 支持从小规模到大规模的灵活部署
