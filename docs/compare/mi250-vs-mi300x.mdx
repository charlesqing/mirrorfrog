# AMD Instinct MI250 vs AMD Instinct MI300X：规格对比与选型指南

## 关键差异

- **功耗**：AMD Instinct MI250 的 TDP 为 500 W，低于 AMD Instinct MI300X 的 750 W，对数据中心 PUE 与散热更友好。
- **显存容量**：AMD Instinct MI300X 配备 192 GB HBM3，多于 AMD Instinct MI250 的 128 GB HBM2e（双芯片），对超大模型单卡承载更从容。

## 常见问题（FAQ）

### AMD Instinct MI250 和 AMD Instinct MI300X 的主要区别是什么？

核心差异在架构与算力密度：AMD Instinct MI250 采用 CDNA 2（GFX90A） 架构，FP8 算力约 暂无公开 FP8 算力数据，显存 128 GB HBM2e（双芯片）；AMD Instinct MI300X 采用 CDNA 3 架构，FP8 算力约 暂无公开 FP8 算力数据，显存 192 GB HBM3。完整参数见上方对比表。

### AMD Instinct MI250 的功耗（TDP）是多少？

AMD Instinct MI250 的 TDP 为 500 W，实际整机功耗还需计入服务器主板、风扇与 PUE。

### 哪个更适合大模型训练 / 推理？

训练看重显存容量、带宽与多卡互联；推理看重单卡吞吐与功耗比。结合上方「关键差异」与「选型建议」按你的 batch size、模型参数量与 SLA 取舍。

### AMD Instinct MI250 与 AMD Instinct MI300X 的显存容量差多少？

AMD Instinct MI250 为 128 GB HBM2e（双芯片），AMD Instinct MI300X 为 192 GB HBM3，差距会直接影响可加载的模型规模与上下文长度。
