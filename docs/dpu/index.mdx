# DPU 数据处理器

DPU（Data Processing Unit，数据处理单元）是专为数据中心基础设施打造的专用处理器，擅长处理网络协议栈、存储虚拟化、安全加密和 NVMe 卸载等任务。在 AI 集群中，DPU 可大幅降低 CPU 负载，让更多算力用于训练和推理。随着 400G/800G 网络普及，DPU 已成为超大规模数据中心的关键组件。主要玩家包括 NVIDIA（BlueField 系列）、Intel（基于 FPGA 的 IPU）和 AMD（Pensando 系列），三者各具生态优势。
