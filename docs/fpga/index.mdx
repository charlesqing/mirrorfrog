# FPGA 可编程门阵列

FPGA（Field-Programmable Gate Array，现场可编程门阵列）是一种可重构硬件加速方案，兼具灵活性与高性能。在 AI 场景中，FPGA 常用于低延迟推理、金融交易加速、视频转码和网络协议处理。相比 GPU，FPGA 的功耗更低、延迟可预测；相比 ASIC，它可在部署后重新编程以适配新算法。适合对延迟敏感或算法尚未定型的场景。AMD（Alveo 系列）、Intel（Arria/Stratix 上的 AI Suite）和 Achronix 是该领域的主要供应商。
