# TPU 张量处理器

TPU 是 Google 自研的专用 ASIC 芯片，针对 TensorFlow 和 JAX 框架下的大规模矩阵运算深度优化，从设计之初就为深度学习工作负载量身定制。Cloud TPU 提供云端训练和推理能力，从 v2 到最新的 Trillium 每一代都在矩阵乘法单元（MXU）、高带宽内存和芯片间互联（ICI）上大幅提升。TPU v5p 和 Trillium 在 LLM 训练场景表现突出，搭配 Google Cloud 的弹性调度和 GKE 编排实现高效训练集群，在 Gemini 等大模型训练中已验证其规模扩展能力。Edge TPU（Coral 系列）面向边缘端推理，功耗仅 2W，适合 IoT、机器视觉和嵌入式场景，为 Google 的 AI 从云到端战略提供了完整落地方案。TPU 的强绑定 Google 生态（TensorFlow/JAX/Vertex AI）是选择时的关键考量，如果团队已深度使用 Google 云，TPU 的性价比优势非常明显。

本分类包含以下 AI 加速芯片/计算卡：

- [Google Coral Edge TPU](/docs/tpu/google-edge-tpu)
